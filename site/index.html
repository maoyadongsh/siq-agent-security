它解决什么问题

能干活的智能体同时握着 Skill 目录、工具、网址、文件路径和密钥引用。来历不明的 Skill 一旦拷进目录，往往已经开始执行。市场上扫描、网关、沙箱、企业台通常是拆开的。本机缺的是一条链：发现 → 审查 → 人授权 → 调用时拦截 → 出事能核对。

  1. 发现

    先盘点本机有哪些 Agent、Skill 和配置。

  2. 审查

    装之前给出结论。静态分析，不执行被扫描内容。

  3. 人授权

    批准权限必须留下操作者姓名。模型建议，人签字。

  4. 拦截

    未授予的能力默认拒绝，例如没批上网就挡住 web_fetch。

  5. 核对

    每次放行或拒绝都有签名回执，可以复核。

日常会看到三种结论

「会用工具」和「是恶意」分开。带工具清单的官方风格 Skill 走附条件准入；隔离留给欺骗和外传。

隔离

欺骗、藏指令、偷凭据再外传、文件被篡改——停，不要装。

附条件准入

声明了要上网、写文件、装软件——记下这些能力，等人签发，而不是一律当病毒。

通过

能力声明干净。仍须人授权后，运行时才放行。

本机程序和企业控制面分开

规则和字段约定共用，运行时分开。不另做一套账号，不自己造沙箱，也不做 HTTPS 中间人。只监听本机地址。

siq-agent-security（本机） 企业控制面
给谁 个人电脑上的智能体 多台机器、多个团队
干什么 装 Skill 前先审查，每次调用工具留签字据 资产台账、审批、采集、策略下发
怎么跑 一个本地程序，不用登录、不用数据库 控制台 + API + PostgreSQL

当前能力表里还没有一行「已正式支持」——没有核验过的档位就不宣称。没有工具钩子就写明拦不住。文件系统和进程策略在沙箱创建时锁定，签发不得把它们标成有效。

在 NVIDIA DGX Spark 上走过的路径

开发机是 NVIDIA DGX Spark（aarch64，Ubuntu 24.04，GPU NVIDIA GB10）。程序为原生 linux/arm64，siq-agent-security 0.2.0。安装脚本不从网上下载二进制。批准人均为人类，模型未代批。能力表没有改成「正式支持」。

接入面 实际做了什么 明确没做 / 不宣称
Hermes 恶意夹具隔离；官方风格附条件准入；人批准后未授予的 web_fetch 被拒；回执核验通过 未配置网络沙箱时不宣称该档
OpenClaw 隔离 HOME 里写入策略与插件后可还原；恶意夹具 block、官方风格 warn 未挂到本机正在跑的 OpenClaw 网关进程
WorkBuddy / CodeBuddy 隔离 HOME 上的真实 PreToolUse 钩子 未驱动图形界面

从本仓库安装

目前尚未上架各平台 Skill 市场。需要 Go 1.22+ 编译本机程序。安装脚本不会从网上下载程序；找不到本机二进制就退出。 

git clone https://github.com/maoyadongsh/siq-agent-security.git
cd siq-agent-security
git fetch origin cursor/agentshield-w0-contracts-8eff
git checkout cursor/agentshield-w0-contracts-8eff

cd apps/agentshield
go test ./...
go build -trimpath -ldflags "-s -w -X main.Version=0.2.0" -o siq-agent-security ./cmd/agentshield
mkdir -p "$HOME/.local/bin"
install -m 0755 ./siq-agent-security "$HOME/.local/bin/siq-agent-security"

完整步骤、适配器与演示夹具见 README 与 本机操作。 发布物： siq-agent-security-v0.2.0。
