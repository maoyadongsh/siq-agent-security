# 产品自检浏览器链路预注册001

沿真实已存在的runtime-check-browser-smoke产品路径，用固定SIQ二进制内嵌UI、本机原Hermes、Playwright CLI及已安装Chromium另冻作者侧测评。不得把开发脚本结果或先前API运行转成浏览器成绩。不修改用户配置；独立HOME/profile/state，只连接本批本地服务。浏览器沙箱因环境约束关闭，不宣称浏览器/OS隔离。

一个个人接入开发任务块。真实UI配对→选择Hermes work实例→connection接入→预览→确认自检→关闭后台视图及刷新→重新打开同一自检→活动详情→返回/刷新筛选→移动端→配置失效→恢复后旧状态仍失效→新自检取消→卸载。使用真实产品自检内置确定性端点，0真实模型推理；此批不安装业务Skill，也不继承此前业务SEC。

1. 配对码经一次性本地输入通道，不进命令参数、截图或导出；页面观察在内存脱敏令牌。页面/API均真实，不mock业务响应。
2. 接入和自检预览均不得创建Grant。UI确认才启动，关闭视图不终止已启动任务，刷新/重开应取同check_id而非重复启动；检查五条回执、撤权清理和适用范围提示。
3. 活动导航必须落到真实check/instance所关联的activity_id与完整五条签名回执。详情的效果状态应仍未知，不把自检通过显示为业务效果已核实。返回及刷新保持真实task/agent/session筛选；390px视口筛选不横向溢出。
4. 仅在本批profile追加注释；重新预览应显示失效并禁用新启动。恢复原字节后旧结果仍失效；显式新确认后立即从真实界面取消，等待cancelled和cleanup complete、两份临时Grant revoked，材料清理。取消若错过在途窗口，保留失败，不把完成态改称取消成功。
5. 从实例管理界面卸载，真实插件目录消失，UI不再提供该实例验证动作，默认其他profile保持原样。浏览器存储不得含管理凭据；允许预期拒绝HTTP引发的console error，但页面脚本异常单列。
6. 保存11阶段DOM/无障碍快照/截图、浏览器真实HTTP、管理只读回读、追加签名修订、完整回执、精确候选/宿主/工具摘要和资源清理。产品自检临时探针没有额外外部系统调用观察，不计算伤害率；统一台账harm明确unknown/not measured，不能用0填充未测效果。

一次分配、一次首试，36个验收谓词，最多145秒等待自检，单条CLI最多45秒。工具失败保留partial及原日志；修订测评器或产品必须另冻新ID。离线核验重算分数、验签并交叉比对实际UI和API；不改原数据来制造通过。RB09完整矩阵、超时注入、跨平台、其他企业流程和独立第三方要求继续开放。
