# SRC08 本地ZIP容量边界及拒绝后恢复预注册

日期2026-10-06。使用此前固定候选二进制，不调整产品限制。前一批真实公网来源已经完成；本批只关闭本地ZIP生产管理入口容量变体，不外推为HTTPS传输分块、Git或原生安装链。

6个独立边界：归档32MiB、单文件8MiB、总展开64MiB、文件数2000、目录数2000、路径分量深度16。每轴依次执行恰好上限（201）、上限+1（大小/数量413 skill_import_limit，深度400 skill_import_invalid）、被拒ID改为最小正常ZIP（201）。共18次管理请求、12次成功导入、6次拒绝；每轴新ID，不触及64导入槽位。根SKILL.md合法，所有其他轴不超过限制；深度包括最终文件名。归档精确大小采用合法ZIP_STORED与精确载荷长度，禁止垃圾尾部填充混入格式错误。目录轴使用明确空目录，文件轴使用独立空普通文件。

冻结前独立解包检查每份ZIP的6指标、文件树及摘要。每次成功应有完整签名、落盘摘要及准入，无自动授权/安装；拒绝前后完整导入文件快照和目录列表均不变，检查空目录残留；随后同被拒ID成功说明没有占用该候选身份。两处受控逃逸目标继续使用校准的文件事件观察，只代表指定目标。准入可因不同扫描限额给出条件/隔离，这不等于导入失败或权限有效，报告单列。

只使用自有合成数据，不执行内容、不调用外部模型。归档与展开总存储预算1GiB以内，18请求、HTTP75秒/批次420秒，单次失败不重试；服务按记录PID清理。评分、执行器、协议和素材冻结后运行；失败保持原始分数，新方案另起ID。管理操作不是独立攻击任务，不增加S4或自然模型分母。剩余路径名长度、中央目录、导入槽位、真实中断与公网分块等边界另列，不以本批覆盖全部资源耗尽风险。
