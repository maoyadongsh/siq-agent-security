# 研究治理、引用与开放边界

[研究总览](../README.md) · [项目治理](../../GOVERNANCE.md) · [贡献指南](../../CONTRIBUTING.md)

研究身份与客户端产品发行分别维护：软件引用身份由 [CITATION.cff](../../CITATION.cff)和[引用政策](../../docs/research/citation-policy.md)规定。研究源码 `research-v0.1.0-rc.1`、历史比赛 V5 与客户端 0.3.0 各有自己的源码和证据；整理目录不发布新版本、生成 DOI 或改变分母。

| 事项 | 唯一政策 / 状态 | 贡献者行动 |
| --- | --- | --- |
| 作者与贡献 | [作者决定](../../docs/research/authorship-decision.md)、[治理](../../GOVERNANCE.md) | 按实际学术贡献与本人同意署名；代码提交量或工具输出不自动构成作者资格 |
| 许可与引用 | [许可范围](../../LICENSES/README.md)、[许可审查](../../docs/research/license-review.md)、[文献目录](../literature/README.md) | 自有代码许可不覆盖第三方 PDF；来源、版本和再分发依据待核的项保持待核 |
| 数据与隐私 | [导出政策](../../docs/research/data-export-policy.md)、[数据卡](../../docs/research/dataset-card.md) | 先审查再公开；禁止发布状态种子、配对码、凭据和客户原文 |
| 发布与长期归档 | [操作记录](../../docs/research/operations-20260908.md)、[权威任务台账](../../docs/open-source-research-tasks-20260908.json) | DOI、论文接受和独立复现仅按已完成证据声明，不由导航推断 |
| 外部评价与冲突 | [外部结果入口](../../evaluations/external/README.md)、[原始模板](../../docs/research/external-reproduction-template.md) | 说明执行者与项目关系、环境和候选；维护者自测不冠以独立认证 |
| 安全问题与历史 | [安全政策](../../SECURITY.md)、[历史导航](../../docs/development/history.md) | 披露按安全渠道处理，失败与勘误可追溯，不重写冻结报告 |

根 `research/` 负责研究主线；原协议、技术报告及有许可/引用绑定的正文保持唯一维护位置。新研究计划先确定问题、对照、样本、预算和协议身份，再执行实验。
