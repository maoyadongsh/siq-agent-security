# 研究发现、证据与局限

[研究总览](../README.md) · [研究问题](../questions/README.md) · [实验设计](../experiments/README.md)

[技术报告](../../docs/research/technical-report.md)是现有工程研究报告，未经同行评审，不宣称首创。[主张—证据表](../../docs/research/claims-evidence.md)及其[机器源](../../docs/research/claims-evidence.json)固定候选、范围与证据摘要；本页不建立第二份手填结果表。

| 要判断的层次 | 权威入口 | 阅读要求 |
| --- | --- | --- |
| 已实现机制 | [报告与实现关联](../../docs/research/technical-report.md)、[方法](../methods/README.md) | 代码存在不等于全部宿主验收，也不等于研究假设成立 |
| 受控实验观察 | [归档复现](../../docs/research/result-reproduction.md)、[原始基准报告](../../docs/hackathon/benchmark-report.md) | 正常完成、 unsafe target、回执与效果分别计数；保留早期失败和后续重跑 |
| 贡献者阶段观察 | [五案例复现](../../docs/research/core-scenarios-reproduction-20260911.md) | 构造案例与候选/证据限制继续适用，不外推总体安全率 |
| 当前工程与发行 | [测评索引](../../evaluations/README.md)、[平台范围](../../platforms/support-matrix.md) | 发行正式版、验签、源码 CI 和原生安装各自成立，不回写历史研究分母 |
| 未知与后续研究 | [原研究问题](../../docs/research/research-questions.md)、[缺口](../../evaluations/gaps.md)、[社区任务](../../docs/research/community-backlog.md) | 外部独立复现、保留集、观察器可靠性、来源分类错误与效用成本需要新实验 |

现有证据的价值是可追溯的实现与具体观察。小样本、自编公开语料、重复任务、可信观察器及环境依赖限制结论；没有观察到不安全效果不构成普遍无风险证明。新发现以新候选/协议/记录追加，勘误保留派生关系，不覆盖冻结证据。
