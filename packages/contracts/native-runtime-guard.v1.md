# 原生可信运行核验 v1

用于 ADR-056 的 Linux 宿主。可信启动器提供实际宿主可见 PID、UID/GID、固定运行制品摘要、解释器摘要、启动参数摘要、受保护挂载及代码文件摘要。PID 不来自 Skill、工具参数或模型消息。必须另有启动后端核验器，逐次证明该进程属于本次拥有的沙箱/容器，镜像与保护配置未漂移；Docker 测试后端不能冒充 OpenShell 业务接入。

核验器持有 pidfd，不按数字 PID 重新连接。核对实际 `/proc` 的用户/组、NoNewPrivs、零有效 capabilities、启动参数、解释器文件摘要和命名空间身份。参数只存 SHA-256，不落原文；不读取或输出进程环境变量。进程退出、重启、身份/命名空间漂移、读取失败和关闭后使用均拒绝。

受保护挂载由启动器固定宿主规范绝对路径和运行时规范绝对路径；只允许 code、skill、channel 三种用途，均须只读。逐次核对真实 mountinfo 的精确挂载点、ro 标志及无覆盖子挂载，并比对运行进程文件视图中的对象与宿主对象身份。不能只信容器管理 API 的 RW 字段。额外可写业务目录由启动后端与既有权限链分别约束，不从这里获得写权限。

代码通过进程真实根目录描述符逐级 NOFOLLOW 打开、核对摘要及读前后对象状态。每个代码文件必须落在固定 code 挂载内。目录代码挂载的实际文件集合必须与声明一致，拒绝未声明文件、符号链接和其他对象；单文件最多 1 MiB、累计最多 16 MiB、最多 128 个代码文件。解释器独立以最多 128 MiB 有界读取核验；父目录、只读底层运行镜像/库的保护由必需启动后端核验，不宣称摘要本身构成不可篡改信任根。

检查前后均核对 pidfd 和启动后端。任何失败永久使本核验器失效，不能自动恢复旧宿主或改绑新进程。只返回固定错误类别；不输出 mountinfo、命令行、正文或宿主路径。只读检查不执行 Skill，不修改 mount，不停止业务容器，也不授予 Grant。

只有以上事实、原生内核凭据通道、实际安装来源解析、签名上下文和最终裁决全部接线后，才可打开对应新身份和日常运行路径。核验器组件或受控 Docker 探针通过不能提高其他后端/平台支持等级。
