# 已安装 Skill 原生来源解析 v1

适用于 ADR-056 Linux Hermes 固定制品。来源事件只有路径/文件/文本摘要，不携带安装 ID、Grant 或宿主路径。可信启动器预先固定每个实例的安装、Claim 签名、宿主根和容器内规范绝对根；最多 64 个，不允许同实例的容器根重复或互相嵌套。模型与工具参数不能新增映射。

来源解析按实际主文件路径摘要唯一选择固定映射。Skill 安装 Store 重新读取签名 Claim、运行绑定和有效 Grant，复验完整安装内容/归属、导入源、移除状态和当前批准版本。主文件必须为安装清单中的 `SKILL.md`；所读文件只能由清单内相对路径映射后的路径摘要匹配，不以事件提供的任意路径读取宿主文件。

在既有有界普通文件读取与路径检查下读取实际主文件和所读文件，核对签名清单里的大小和原始 SHA-256；单文件上限 1 MiB。文本摘要严格遵循固定 Hermes 的 UTF-8 BOM、errors=replace 和 universal-newlines 语义。返回只包含摘要、长度与安装引用，不返回文件正文。宿主根仅供内部挂载验证，不作公共 JSON 输出。

读取前后分别重新检查有效安装授权。独立必需挂载验证器确认此宿主根仍以只读方式映射到固定容器根，并核对可信启动归属、运行制品及无覆盖子挂载。映射声明或摘要本身不能替代实际挂载核验。不存在、歧义、参数漂移、错误摘要、缓存漂移、撤权、移除、源/目标修改、非普通文件或挂载变化均拒绝。

该接口只读，不安装、不重新授权、不更改 mount。文件检查不宣称抵御可修改可信宿主或内核的攻击者。运行时身份、任务/父链、签名 SEC、最终调用与在线裁决仍由原生宿主桥接及既有引擎负责；缺少实际挂载验证器时不能启用解析器。

Hermes 现有安装事务使用“目标文件＋私密事务归属文件”的硬链接对。原生读取器默认仍仅接受单链接；受保护 bootstrap 可显式启用受管链接对模式，额外接受恰好两条链接，三条及以上仍拒绝。该模式要求每次来源观察由本解析器核对签名安装与事务归属文件确为同一对象，并通过实际只读挂载核验后才返回文本；不能给普通插件或未验证回调默认开启。文件描述符、链接数及读取前后完整状态继续复验。元数据 v1 不新增授权字段，模式不能由 Skill 或工具请求指定。
