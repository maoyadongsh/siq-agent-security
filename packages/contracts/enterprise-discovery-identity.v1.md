# 企业发现来源身份 v1

设备上报候选的身份由服务端确定：tenant_id + 已认证 Edge 的内部 ID（discovery_scope）+ source_type + source_locator。不使用客户端属性声明设备归属；同设备同位置重复采集复用资产，不同设备/环境同名同位置必须分开。

不可变证据观察键增补 collector_id，由设备身份及签名核验绑定；同一环境不同设备产生同外部 evidence_id/相同内容摘要时仍保留各自观察和签名。候选确认推导默认实例环境、资产证据列表均限制到该发现设备及环境。

历史资产迁移为 discovery_scope=legacy，不推测或重新分配历史已合并的归属。新扫描不自动合并到 legacy 资产，需要后续人工迁移/复核。历史证据保留原采集者；不可自动补出之前丢失的观察。此增量是框架/角色/Skill 关系的来源身份基础，不代表完整关系图已交付。

非 legacy 资产的威胁扫描引用证据时，必须是该资产已关联或 subject_ref 直连的证据，并属于相同发现设备/环境。artifact_digest 不匹配时，替代内容摘要也只能在对应设备证据中匹配，不能借用其他设备同外部 evidence_id 的观察。错误引用在分析和隔离等状态变化前拒绝；既有权限检查、静态威胁分析规则和审计不变。历史 legacy 归属仍待人工复核，不声称此增量修复全部历史关联。
