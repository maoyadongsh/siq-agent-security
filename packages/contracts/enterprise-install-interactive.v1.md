# 企业安装交互确认 v1

Linux `setup-enterprise --interactive` 在真实终端展示经过计划校验的组织、环境、控制面、平台、采集目录/文件和服务启动选项，默认拒绝，只有输入完整 `yes` 才绑定本次读取的原计划 SHA-256 并继续已有安装链路。不能与 --review-only、--confirm-plan-sha256 或 --enrollment-code-stdin 混用；无终端不接受交互确认，自动化继续使用原显式摘要模式。

计划和终端校验后、确认提示前，复用 enterprise-host-inspection/v1 的固定只读范围
展示本机 OS/程序架构、uname、发行版及产品型号来源。仅本地显示，不进入注册、心跳
或计划数据，不扩展已授权采集范围。缺失/权限不足明确标注，不显示成不存在设备。
环境名称不是硬件证据，型号不是硬件认证，不证明 GPU/OpenShell 安装或防护生效。
输出失败停止确认流程；非交互、review-only 和帮助路径不新增主机探测。

交互模式新设备在制品验签/暂存/能力核验成功后，才提示输入一次性注册码；输入关闭终端回显，结束/失败/取消恢复终端属性。已有设备复用身份，待恢复注册仍走原恢复流程，不重复索取注册码。不打印注册码、设备密钥，不把注册码放入进程参数。

仍必须独立传入 tenant/environment/control-plane，不能从未验证的计划自动选择注册服务。计划变化、过期、错环境、签名失败继续拒绝；交互确认不替代发行验签。默认仅配置服务，--start 经提示确认后启动当前用户服务，不提权、不启用 linger，不授予智能体业务权限。不构成真实安装与首扫验收。
