# 指定设备扫描 v1

POST /api/v1/scans 可选 target_device_identity（8–128 字符），明确指定环境内未吊销设备；目标不存在/其他环境或租户时 404，已吊销时 409。省略保持环境级领取。不根据客户端目标派生租户，仍使用验证身份及环境授权。

目标身份进入 payload.target_device_identity，因此受现有任务签名保护，不需要数据库迁移。领取 SQL 在分页前及原子 claim 时按设备身份过滤；lease 过期不允许其他设备接管定向任务。结果上传与回执也核对目标，防止绕过领取直接写入，终态幂等回执不能绕过此检查。

新 Edge 在验签/期限检查后、范围检查和本地结果复用前核对目标，不匹配返回 task_device_mismatch，且不执行 Connector。旧无目标任务兼容。旧 Edge 缺少本地门禁，仅有新服务端限制，不可据此宣称旧版本完整防御；企业交付必须使用配套版本。能力检查不替代本字段，二者同时约束领取。

此增量不自动签发扫描，不批准任何业务权限；UI 设备选择和自动首扫后续接入。
