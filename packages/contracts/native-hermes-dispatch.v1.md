# 固定 Hermes 原生分发接入 v1

适用于 ADR-056 的 Linux 受控运行制品，非旧插件自动升级。运行制品由固定源摘要、原生补丁和 SIQ 桥接代码共同标识。源码漂移时停止生成补丁，不猜测适配任意 Hermes 版本。

## 任务与加载

可信 bootstrap 必须在处理用户任务前一次性配置来源观察、最终裁决和结果观察三个必需回调；没有配置的原生入口拒绝执行。回调由受保护启动器提供，模型、Skill 和工具参数不能选择回调。接入层不持有管理凭据、规则或签名私钥。

原生 run_conversation 的实际 task/session 进入任务作用域，正常返回和异常均结束作用域。任务 ID 在进程内不得重复，记录有界，不清除旧任务来恢复容量。子任务缺少精确可信父任务边界时拒绝，不以父 session 猜测父任务。普通并发用户任务独立；同一任务的最终分发串行，防止 Skill 加载与其他工具执行交叉后丢失归属。

实际普通/插件 SKILL.md 和支持文件读取必须消费 SkillSourceReader 返回的同一份文本。Hermes 缓存返回前仍核验实际文件并观察；缓存清理不能清除任务来源。失败使任务不可继续，无 Skill 只能由仍有效且没有加载事实的任务后端确认。该 profile 不执行 Skill 内联 shell/模板预处理；普通文本返回保留，不能把未执行的预处理称为成功授权。

## 最终执行边界

原生 registry.dispatch 在 request/execution middleware 后、真正 handler 前调用必需门禁。原生 tool_call_id 从 model_tools 显式传递，不转交给原 handler。缺失任务、session、调用 ID、重复调用、已结束任务、回调失败均拒绝。直接调用 registry 也必须经过门禁，不依赖可跳过的 pre hook。

最终参数先以有界严格 JSON 复制，授权和执行使用同一份私有快照；同任务调用 ID 消耗后不得再执行，即使裁决响应丢失。最终回调输入含实际平台/Agent/session/task/tool/call 和参数。参数摘要采用现有 trustedcontext.RequestBinding 规范；回调返回必须精确包含 `action`、`request_binding`、`decision_id`，仅已关联该请求的 allow 可以执行。deny/hold 均不执行；redact 或未知响应不静默改参数。

三个回调是接线接口，不是网络认证或授权实现：来源回调完成只返回 None，最终裁决必须来自既有签名权限引擎，结果回调只观察实际函数返回/抛错。不得用固定 allow 回调部署产品。传输通道的元数据确认不能作为最终裁决。最终大参数仍走既有有界裁决接口，不扩展元数据通道为任意执行通道。

结果观察只声明 handler returned/raised，不声明文件/网络效果已经独立核验。观察失败后停止任务并保留执行不确定性，不能自动再执行。普通宿主插件、原生类型检查及权限门禁仍然保留；本强制门禁不把其他插件异常变成 SIQ 允许。

## 信任与启用边界

补丁、桥接模块、解释器和依赖必须由可信启动器固定并以只读制品加载；主进程必须经内核通道认证。仅把 Python 文件放到可写用户目录，不构成独立信任根。允许控制同进程代码、root/内核或重配启动器的攻击者不在本 profile 保证内。

在宿主事实发布、Go 上下文/调用存储、在线裁决和受保护部署接线完成前，新身份创建仍关闭。固定源码原生函数测试只证明补丁实际经过这些路径，不证明日常业务已启用、安全效果或跨平台支持。
