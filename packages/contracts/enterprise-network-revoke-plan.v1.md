# 企业网络允许项撤除规划 v1

ENT-015 的内部纯规划合同，不是执行或授权 API。输入为完整期望策略对象及 1–256
个精确选择项，每项仅 endpoint 与 binary_path。只处理已有 OpenShell 编译器支持
的 L3/L4 allow 词汇；规则总量、每规则路径及展开总量沿用网络变化判定 v1 限制。
未知字段、条件、deny、通配/非法端点或路径不得剥除后降级为可规划。

选择项先经现有规则验证器规范化，同一端点/程序对不得重复。每个选中对必须存在
于基线允许集合，否则拒绝 stale selection；不得把“未找到”视作撤权成功。删除时
移除所有重复规则中的该允许对，保留未选中路径及规则名，删除没有剩余路径的规则。
结果必须由既有 assess_network_change 判为 narrowed，否则拒绝。撤掉最后一项的
结果为显式 network=[]，不是 None（省略配置）；不能解释为整台设备完全断网。

函数返回原策略的独立深拷贝，仅 network 改变；不更改档位、selector、其他权限域、
状态、版本、审批或身份。不修改原对象，不写数据库，不执行策略。不自动生成新的
策略版本或批准变更；后续提交仍须创建新版本、绑定操作者及摘要、走原审批、目标
归属、CAS、影响确认、后端能力和读回流程。

本合同只证明受支持词汇中的集合严格收窄，不证明该期望策略与实时沙箱相同、
不存在其他授权来源、某个 Skill 独立被撤权，或撤销已生效。实际执行前必须重新
读取目标策略/revision，并验证撤除方案及共享影响仍适用。
