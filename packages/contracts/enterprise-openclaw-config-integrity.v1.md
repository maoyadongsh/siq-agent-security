# OpenClaw 配置完整读取 v1

这是静态配置采集的完整性约束，不改变既有上报字段或角色身份。

- 配置摘要必须来自完整原始文件，不来自预算截取前缀；前缀即使是合法 JSON/JSON5，也不得产生候选、配置证据或声明权限。
- 通过既有安全打开取得文件描述符，在该描述符上核对普通文件类型及读取前后大小、修改时间。超过剩余预算返回截断状态，且不返回可供解析的部分数据；已经完成的其他配置根结果可保留。
- 读取长度与读取前大小不一致，或读取后大小/修改时间变化，拒绝本次读取，经既有错误分类返回不可用；不输出原始配置或主机路径。
- 正好等于预算的完整文件可被采集，证据摘要包含注释和尾部空白。

描述符及元数据检查不能证明文件系统快照原子性，也不防止有能力恢复元数据的本机攻击者。来源证据不是运行时绑定、技能加载或有效授权证明。没有扩大扫描范围或读取额外配置文件。
