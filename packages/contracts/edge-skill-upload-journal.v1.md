# Edge 技能上传日志 v1

技能批次必须在首次 HTTP 前持久保存原始已签名 JSON；重试复用它，不重新扫描或生成新的 observed_at。当前日志组件尚未接入 task runner，不单独构成上传授权。

Linux 状态目录下 skill_uploads/<task_id>.json，新建私有目录 0700、日志 0600，逐级 openat/O_NOFOLLOW 检查路径，拒绝非本人目录、宽权限、链接/硬链接、非普通文件和超限文件。仅新建写入并 fsync 文件及父目录；存在时只读校验，相同内容幂等，不同批次拒绝覆盖。失败或半写日志保留并阻止自动重扫，不自动删除/重建身份。调用方须遵守现有任务锁，日志本身的 O_EXCL 另防覆盖竞争。

日志记录 schema、任务内容摘要、设备上下文摘要、批次摘要和完整签名 body。上下文摘要覆盖控制面地址、环境、设备身份、设备公钥、控制面公钥和已确认计划摘要，不包含设备 secret 或签名种子。每次读取重新核对任务签名、上下文、body 任务与 scope_digest、body 摘要及设备签名。任务更换、环境切换、批次篡改均拒绝，不把缺失/损坏误判为可重扫。

只有确实不存在该日志才返回 absent；权限问题、损坏、同名链接等返回固定错误。任务过期/吊销/当前确认范围仍由执行与服务端门禁独立检查，读日志不能绕过它们。其他 OS 明确 unsupported。原有智能体扫描日志/回执语义不改。
