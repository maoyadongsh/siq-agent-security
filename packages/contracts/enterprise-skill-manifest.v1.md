# 企业 Skill 清单静态解析 v1

本合同定义独立技能模型所用的纯解析结果，不把技能转换成 AgentCandidate，不证明任何框架/角色归属，不执行内容、不联网、不授权。调用者须在已确认扫描范围内安全读取完整 SKILL.md；文件系统边界与读取限额仍由采集器负责。此阶段尚未接入发现上传或前端。

输入限额 256 KiB，UTF-8。超限不产生摘要或权限结果，避免把截断内容当成完整版本。其余输入的 content_sha256 为完整字节摘要，仅代表 SKILL.md，不冒充包含脚本/依赖的完整技能包版本。

输出 status 为 parsed、missing_frontmatter、unsupported、invalid_utf8 或 too_large。仅 parsed 时提供 name 和 declared_tools；其余状态清空声明，不等同于没有权限。allowed_tools_present 区分字段缺失和显式空列表。body 不参与权限推断，也不输出正文、description、未知字段、命令参数或解析错误原文。

支持开头 --- 与结束 --- 之间的有界简单 frontmatter。name 为 1–128 字节机器标识；allowed-tools 支持以空白/逗号分隔的简单机器工具名、方括号列表及缩进的 - 列表。最多 64 个工具，去重排序；工具名限 ASCII 字母数字及 _ . : / -，必须以字母开头。支持简单成对引号包围标量，不支持转义、模板、YAML 对象、锚点、标签、参数表达式或复杂引用。重复目标字段、未闭合头部、无效目标值均返回 unsupported，不返回部分声明。未知字段不作为权限来源，其缩进行忽略；不会声称完整 YAML 解析。

现有反攻击准入、威胁规则、隔离和运行时裁决保持独立。解析成功不表示内容安全；正文中的注入仍应交原有检测链路。新增技能关系模型、证据上传和可视化必须另外完成与验证。

名称/工具标识若命中既有 siq.redaction.v1 凭据模式，返回 unsupported 并清空声明，不输出疑似凭据。此正则门禁不声称能识别所有秘密；正文和未知元数据始终不输出。
