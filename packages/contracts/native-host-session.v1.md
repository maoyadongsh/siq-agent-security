# 原生宿主会话生命周期 v1

本接口是可信宿主服务的进程内编排接口，组合已有 OpenShellBackend、RuntimeGuard、Verifier、NamespaceHostChannel、DecisionRelay 与 HostLoop。业务跨进程控制协议须另行提供认证传输；不能把本接口当作已开放的 HTTP 管理入口或允许兄弟仓库导入内部模块的依据。

## 业务监管边界

每个受管会话绑定一个真实业务监管进程的 pidfd，监管者 PID/UID 来自可信启动器或后续控制通道的内核凭据，不能来自模型、工具请求或普通 HTTP 正文。监管进程退出、关闭、fork 后控制或心跳期限到达时，原生运行核验拒绝。

整体结束期限固定，最多一小时；业务心跳窗口最多 90 秒，同时以 UTC 与单调时钟约束。续期仅能在旧心跳仍有效时由原监管进程执行，且不能超过整体期限。心跳是业务监管者完成既有授权/执行租约复查后的报告，不是 SIQ 自行批准业务权限；本接口不自动续期、不查询兄弟数据库、不接受模型续期，不允许过期后恢复。

带业务监管边界的 guard 在实际 RuntimeGuard 核验及安装核验前后检查监管者与期限，Publisher、Verifier 与 HostLoop 使用同一个受监管 guard。观察到停止、退出或过期后不能返回允许结果。最多 90 秒是失联的上限，不宣称业务权限变化在未复查前已被即时获知。

## 所有权与启动顺序

HostSession 接受可信启动器固定的 backend 参数、guard 参数、subject、安装映射、通道目录、运行身份凭据及绝对截止时间；不接受替换后端、任意回调或由模型选择的端点。daemon 的 loopback 端点和 Verifier 由所属宿主服务固定。先核验真实后端与进程，再建立监管边界、登记 Verifier，最后创建运行端通道并启动持续循环。任何失败都回收本次已取得的资源，不能回退旧插件。

一个对象只启动一次，失败或关闭后不能重启。状态检查不能续期，也不等于业务任务完成。关闭先停止监管边界，再停止并等待循环；未确认工作线程退出时不得提前释放其使用的 guard/目录句柄或宣称清理成功。确认循环退出后关闭通道目录作用域，再关闭真实 guard 与监管者 pidfd。清理只作用于本会话，不关闭共享 Verifier，不删除容器；精确容器回收仍由业务 Supervisor 负责。

Verifier 中原登记不复用，关闭 guard 后该登记永久拒绝。不会恢复历史在途调用，不把关闭解释为已执行动作回滚。此组件验收与日常 builder/Supervisor、模型完整会话及其他平台验收分开记录。
