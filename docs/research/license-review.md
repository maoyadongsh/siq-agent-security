# Source and dependency license review

Owner decision: rights-decision.md. Machine-readable source inventory includes all five OpenClaw patch files with target/version/digests and preserved MIT attribution, plus Mermaid 11.4.1 and its 70 distinct pinned source-map dependency packages. The upstream Mermaid bytes match the local file prefix exactly; the local export alias is the recorded modification. All 70 packages yielded upstream license/notice texts, retained under LICENSES/third-party. OpenClaw is identified by npm version and exact target hashes; an upstream Git commit was not independently established and is explicitly unknown.

The Web lock inventory contains 165 packages including optional/dev/transitive packages. Every installed non-dev dependency has its license text retained, including all four OFL font packages. The Python lock inventory contains 48 dependencies with local installed metadata where available and runtime/development classification. Thirteen Go module files are recorded; dependencies are the standard library and local project modules. Scope and unknown platform-specific metadata are explicit in the inventories.

The owned source grant and retained upstream notices are ready for source review. This is an engineering provenance inventory, not an unqualified legal compatibility certification. It does not claim that model terms, third-party papers or previously distributed binaries are relicensed. No dependencies were upgraded, replaced or removed to obtain a passing result.

Before publishing a new binary bundle, inspect actual Web emitted assets/build helpers and embedded fonts, copy the Go runtime license, carry all needed notices, and generate an SBOM for the actual payload. Existing V5 packaging has a scoped SBOM; it must not be described as complete for a new distribution merely because these source inventories exist. Owner of remaining binary-distribution review: @maoyadongsh.

License texts were downloaded from the SPDX license-list-data repository when the Apache/CC servers denied command-line access; official terms were cross-checked at https://www.apache.org/licenses/LICENSE-2.0 and https://creativecommons.org/licenses/by/4.0/. DCO 1.1 source: https://developercertificate.org/. Package text provenance and exact package hashes are in the inventories. Unknown provenance must be resolved or the affected material excluded from a future artifact before that artifact is called license-complete.
