# SIQ 第三方测评工作范围

版本 1.1，2026-10-06。本文是供后续协商的测评工作范围和交付验收草案，配套[合并方案](../third-party-evaluation-plan-20261006.md)。当前没有委托机构、报价、执行记录或认证结论。

## 1 委托目的

独立回答选定 SIQ 候选在明确权限、宿主与任务条件下，能否限制未授权动作、核验真实效果、正确呈现完成状态，以及对合法任务和成本有何影响。交付应包含失败、未知、局限和复现材料，不以获得通过率或论文录用为目标。

## 2 开始前登记

双方在执行前确定以下字段，登记到冻结协议：

| 类别 | 必填内容 |
| --- | --- |
| 对象 | 产品提交/包摘要、dirty 状态、构建输入、适配器及测试构建身份 |
| 环境 | host OS、execution OS、架构、宿主版本、后端版本、模型和依赖 |
| 范围 | 主张 C1–C7 的选择、适用入口、攻击者能力、已知不支持项 |
| 方法 | 产品专项/公开基准/隐藏集、实验组、原子案例分配、外部判定器 |
| 资源 | 人员工时、设备、模型端点、token/金额/时间/磁盘与并发上限 |
| 独立性 | 执行者与复核者身份、与作者关系、资助、作者协助、材料权限 |
| 资料 | 原始记录保管位置、留存期限、公开/匿名范围、漏洞披露方式 |

公开案例复现与独立隐藏集分别选择，不能购买公开复跑服务却在报告中称盲测。原生桌面、真实客户 IdP、跨设备、强隔离或真实 SaaS 业务效果只有明确纳入并具备环境时执行。

## 3 职责和结论权限

作者方提供候选、构建说明、公开开发集、机制边界及已知失败，回答事实问题并披露帮助。作者不能读取未解盲隐藏题来调整防御，也不能要求删去失败、修改 oracle 答案或用新结果覆盖旧结果。

执行方独立校验/构建候选，控制隐藏集、实际运行、原始终点和评分器。执行方有权出具 finding、inconclusive 或未评估结论；报酬与产品是否通过无关。报告中的作者事实澄清作为有记录的修订，不形成委托方单方改结论权限。

复核者核对全部严重发现、全部未知/冲突及至少 10% 其余无异常样本。无异常样本按任务块分层抽样，覆盖模型、宿主和实验组；冻结抽样 seed、向上取整规则和最少一例规则。复核与执行为同一人时如实披露，不虚构双人独立复核。

支付与实质研究协作均须披露。若外部人员作出研究贡献，按实际贡献和适用投稿政策处理身份，不能为保留“独立”标签而隐瞒合作关系。

## 4 最小工作包

| 工作包 | 工作内容 | 可核验交付 |
| --- | --- | --- |
| W0 协议与候选确认 | 校验对象、依赖、威胁模型和适用性 | 双方确认的冻结协议、候选摘要、范围排除理由 |
| W1 测量自测 | 校准真实效果/无效果/失联/瞬时事件，检查 oracle 保护边界 | 校准原始材料、权限探针和可用观察范围 |
| W2 公开复现 | 按约定重跑仓内回归及机制样例 | 全部尝试、原始退出码、回执和独立终点；分别保留历史与新结果 |
| W3 独立隐藏集 | 建立新任务块并冻结，按同模型/工具/预算配对执行 | 隐藏集承诺、分配清单、运行日志、原评分与外部结果 |
| W4 复核与差异分析 | 核查 findings、未知和抽样正常结果 | 复核记录、可复现步骤、作者澄清和分歧处理 |
| W5 交付 | 完整报告、受控公开包与重建说明 | 报告、机器记录、摘要清单、限制、初测复测关系 |

默认小规模隐藏包是 20 任务块、一个模型、三臂两次重复共 240 次执行，前提为 A-PROV 可隔离且已通过验证。若改为两臂，先冻结 160 次协议并将来源因果结论移出范围。没有新增隐藏任务时，只交 W2 外部复现，不提升标签。

## 5 隐藏集与材料控制

隐藏任务由执行方选择或生成，合法任务、攻击面和 oracle 规则与项目支持范围一致。任务按家族分开，避免公开模板改姓名被包装成广泛未知任务。作者看过的旧失败、PR 案例及公开 30 族均作为开发/回归。

冻结时提交带随机盐的任务清单承诺或加密归档摘要。盐、解密材料及原始输入由独立方保管；授权复核时提供可验证映射。作者只能获得范围、工具和授权策略等必要接口信息，不能获取隐藏攻击目标来定制允许列表。

产品配置所需授权由干净用户任务和预先批准的业务政策产生，禁止使用 oracle 答案生成权限。外部真实状态与产品 EVC 材料分别保管；原始日志不是被测 Agent 可写文件。

## 6 失败复核与复测

每项 finding 至少包含候选、协议、任务 ID、攻击者能力、前置授权、实际派发、外部效果、产品状态、用户可见输出、严重性理由和复现步骤。先区分策略范围缺口、授权检查缺陷、集成旁路、证据/完成错误、展示错误和实验故障，再讨论影响。

初测失败不得删除。修复后产生新候选，旧题复测归回归；题目一旦向作者披露，不再声称是对作者隐藏。需要继续验证未知攻击能力时，由独立方补充新任务并重新冻结，记录追加预算。

严重性不由攻击提示是否“看起来危险”决定；依据实际权限、可达对象、产生效果及恢复成本判断。模型没有提出危险动作不等于 SIQ 已拦截；固定提议的机制测试单独补充。

## 7 两种验收

测评交付合格：完整执行或逐项说明无法执行的原因；所有尝试可追溯；测量质量和分母可核对；失败、未知与作者协助完整披露；提供可重算结果与约定范围的材料。发现产品缺陷仍可验收测评交付。

产品主张成立：另按主方案第 13 节检查确定性不变量、效果覆盖、正常效用及确认性比较。未观察到损害不自动证明普遍安全；采集缺失、样本不足或基线无区分力只能得出范围受限或 inconclusive 结论。

交付标签仅使用已证明的类别：作者方测评、协作者验证、公开套件外部复现、独立隐藏集评测。专业机构报告如存在须注明签署范围；工具品牌、资助或数字签名不等于标准认证。

## 8 输出清单

1. 完整报告与一页范围限定结论。
2. 冻结协议、候选/工具/语料/模型身份和全部分配清单。
3. 命令事件、逐例/逐尝试记录、外部终点与产品材料关联。
4. 机器可读指标及独立复算入口，含缺失边界和所有分母。
5. Findings、复核记录、初测/修复/复测差异。
6. 关系、资助、作者协助、数据访问和结论权限声明。
7. 可共享的脱敏包、摘要清单、可信公钥来源及原始材料受控访问说明。
8. 未完成环境、未支持路径与后续需要的独立工作。

## 9 费用、停止与公开

工时、模型、设备和复核费用分别估算；先使用开发集估时/估量，可预留 20%–30% 的失败分析与复核预算。该预留计入总授权上限，不自动增加允许调用量。付费条件按交付范围，不按安全通过率。

真实凭据、范围外资源变化、未知出站目标、失控资源或 oracle 故障触发停止并保留安全现场。实验外层围栏介入时单独标注；不得把实验室代阻断计为 SIQ 成功。

公开、上传或向他人发送材料需符合实际授权范围；本文件本身不构成发送指令。论文匿名版采用匿名执行者标识并保留关系类别，不带本机路径、机构抬头或可识别签名。脱敏改变内容后生成新封套，不声称仍具有原报告签名。投稿时间与可更新阶段在确有投稿任务时另查官方规则，不沿用历史截止日期决定产品测评范围。
