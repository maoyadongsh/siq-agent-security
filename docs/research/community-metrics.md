# Research community metrics

Count external reproduction attempts, successful full reproductions, partial reproductions, failures, time to resolve blockers, accepted case/metric corrections, independent contributors and actual citations. Keep maintainer/local automated tests separate. Denominators include submitted failed attempts; a missing report is unknown, not success.

Initial external reproduction/independent-review/citation data: no submissions collected in this cycle. This is not a claim that no unknown external user exists. GitHub star/download counts are discovery indicators, not research validity. Do not infer independence from a different runner or account without an actual statement.

No automatic user telemetry or collection of private environment/contact data is introduced. Contributors choose what sanitized environment information and attribution to share via the external reproduction template. Record metrics snapshots with observation times and query scope when real reports arrive.
