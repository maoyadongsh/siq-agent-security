# Competition scope and limitations

- **Provider:** Step Plan is now primary and actual inference is evidenced;
  local ornith is the explicit backup. Each provider has separate attempts and
  results. No StepFun result is inferred from ornith or FixtureProvider.
- **Model quality:** the latest five benign tasks completed; earlier cohorts
  include JSON-format, timeout and length failures. The sample is too small for
  general reliability, semantic-review quality or attack-susceptibility claims.
- **Sources:** a selected-file live GitHub task succeeded. Anonymous quotas and
  network failures remain possible. Controlled-source benchmark runs are labelled.
- **Authority:** SIQ enforces selected actions through the built-in gateway.
  This does not establish universal semantic provenance or protect against
  arbitrary hostile Python code/same-UID host processes bypassing that gateway.
- **Effects:** file bytes and controlled HTTP receiver events are observed.
  The receiver is on the same host and is not independently administered.
  External email delivery, arbitrary SaaS outcomes and subprocess effects are
  not universally attested. Process PID/digest remains reported evidence.
- **Runtime integration:** installed native harnesses cover specific loaders,
  hooks, tools and CLI calls. Their synthetic operators and bounded runs do not
  establish every native conversation, GUI, channel or human-approval path.
- **Operations:** demo state and credentials are local and isolated. Pairing is
  loopback-only. This is not a production availability, HA or Linux isolation claim.
- **Performance:** DGX hardware and local measurements are real; model transport,
  whole-task and Go component populations differ. Small-sample percentiles are
  descriptive, not an SLA, GPU-kernel profile or saturation benchmark.
- **Release:** local validation is not remote required CI. Repository protection,
  official release signing, native installation on every OS and RC publication
  remain separately tracked. No stable release, external email or push occurred.
