- 不实施仓库目录调整，不搬移文献、历史证据、Go 模块、内嵌 UI 或适配器资源。

- 不启动新的局域网团队功能开发，不更改共享网关、生产身份系统、全局网络或系统时间。
- 不伪造正式签名、后台停止确认、行为执行能力、外部测评或实机通过。
- 本任务书不新增提交/推送/合并/正式发行授权；执行会话如已有明确覆盖本批的授权，按第 13 节检查后执行，不重复索要。

4. 检查 Go/Node/Python、真实宿主、浏览器、systemd user、OpenShell CLI/endpoint 的可用性；版本来自实际命令，不抄历史。
5. 先做相关组件回归，再构建预验候选；存在产品修复时递增候选 ID。最终功能稳定后冻结交付候选。

- 错误 CLI、缺 endpoint、未配置/无效绑定等现有五类负向均在后端 I/O 前拒绝；有效显式绑定有正向对照。

- 每次真实验收前后复算候选与驱动摘要；不允许运行中重编译覆盖候选。
- 只变驱动时保留产品候选身份，但新的驱动实测有独立证据；产品变化则新候选并重新完成受影响验证。

## 7. LX03：双宿主原生审批消费与权限边界

参考 `hermes-approval-gap-native-smoke.py`、`r01-sec-hermes-native-smoke.py`、`r01-hermes-service-down-smoke.py`、R07 驱动，以及 `adapters/runtime/`、`apps/agentshield/internal/` 中实际 hold/receipt/server 调用链。先定位入口，禁止猜文件名创建平行安全实现。

### 每个宿主独立执行的场景

| 场景 | 预期与外部见证 |
| --- | --- |
| 权限内普通调用 | 真实工具成功，回执与权限、SEC、安装身份对应 |
| 需审批调用未批准 | 原生入口暂停/拒绝；临时文件计数或其他无害效果见证为零 |
| SIQ 批准后原生重试 | 原生消费批准后产生一次效果；仅 resolve API 成功不算闭环 |
| 已消费批准重放与并发提交 | 按合同拒绝/报告已消费，不产生第二次效果 |
| 批准后参数、对象或安装摘要变化 | 拒绝旧批准，零新增效果 |
| 批准后撤销 Grant / SEC 到期 | 拒绝，错误及回执保持一致 |
| 服务不可达 | block 模式 fail-closed，宿主侧零新增效果 |
| 有效身份与 Grant 下的越权 | 越界目录/目标/动作被拒；同权限内合法对照成功 |

“权限内越权构造”指身份和权限配置本身合法，但具体请求超出其资源/动作边界；不能用缺 SEC 的拒绝替代这项。

效果计数器、目录、目标均使用无害本批 fixture。需要进程重启验证时记录执行前后状态；未覆盖跨进程竞争/外部效果与本地状态的原子提交，就只称当前边界下一次消费，不声称分布式 exactly-once。上游能力不足保持 partial，同时完善清晰的拒绝与恢复说明。

## 8. LX04：原文保留与导出隔离

参考 `closure-b04-export-runner.py`、`closure-b04-expiry-seed-runner.py`、`test_b04_expiry_scope.py` 及当前原文采集/清理实现。先区分三个独立概念：运行权限期限、采集授权期限、已采集密文保留期限。

**范围修订（2026-09-19，项目负责人指令）**：取消补充性的“管理员会话连续运行 12 小时后再验证导出拒绝”实测，不等待该时钟腿；该腿记 `out_of_scope`，不得记通过。LX04 原验收仍以真实宿主原文采集、采集许可自然到期、A1=1 小时/A2/B1=24 小时真实密文保留与到期清理、任务隔离、默认导出排除、显式注销撤权及畸形范围拒绝为准；这些已有独立证据。

### 实施与验收

1. 新状态默认不采集；两个独立任务 A/B 分别通过真实宿主产生有标识的无敏感测试内容。
2. 仅 A opt-in 时，A 可采集、B 不采集；撤权或采集许可自然到期后 A 新调用不再增加原文，运行权限本身按独立 Grant 判断。
3. 创建有真实保留期限的到期对象 A1 和尚未到期对象 A2/B1，记录密文摘要、期限、可公开元数据与私有核对材料。
4. 使用产品支持的期限配置自然等待；禁止改系统时钟、篡改持久时间戳、降低生产最低期限来冒充实机通过。若耗时超过会话，持久化待验证清单和可续跑命令，状态 pending/partial。
5. 到期后经真实清理入口验证 A1 消失/不可读，A2/B1 字节摘要保持，回执链完整；重复清理幂等，恢复后结果一致。
6. 默认导出不包含原文仓、凭据、私钥；任务 A 导出不得包含 B 的内容和受限元数据。原文导出如产品支持，必须走既有独立授权；不新增默认权限。
7. 导出授权撤销/到期后新导出被拒；恶意任务 ID、路径穿越、无权限访问有负向。已交付用户的外部副本不能宣称可被远端撤回。

采集许可到期通过不能关闭保留期删除；清理 API 返回成功不能替代磁盘与内容核验。测试注入时钟只能记组件证据。

## 9. LX05：浏览器恢复与诊断可靠性

- 给配对、重启、会话失效、重新配对、页面就绪设稳定阶段 ID 和等待条件，采集脱敏请求结果、DOM 状态及服务健康信息。
- 用候选内嵌 UI 与固定浏览器版本执行正常恢复及有控制的慢就绪场景；确定性测试覆盖旧响应不能覆盖新会话、重复提交、401 后正确回到配对页。
- 不把固定 sleep 增长、无限重试或仅更换 locator 当根因修复；超时上限依据阶段语义设置，失败应明确归因。
- 失败样本原样留存；截图、trace、HTML、console 可能含配对码和凭据，原始文件放私有区，公开报告只输出固定阶段标记和安全摘要。
- 若历史 flake 无法重现，明确“未复现、原因未证实”；诊断增强可以完成，根因修复项保持未关闭。新诊断自身需有故障测试证明能捕获失败阶段。

## 10. LX06–LX08：性能及条件任务

### LX06 当前候选真实 OpenShell 验证与性能

复用 `openshell-o05v6-d05-acceptance.py`、`openshell-o05v6-taskexec-journey.py`、`openshell-b2b3-perf-protocol.py`、`openshell-o04-perf-protocol.py`；先读参数及既有协议，不能凭历史命令猜当前参数。

1. 对本批独占沙箱运行绑定、加载、授权、提交、证据持久、超时、恢复和重放等受影响的真实验收腿。
2. remote_stop 未获后端确证时不报 stopped；本地进程结束和远端任务停止分开。后端加载期间禁止叠加不受控写入，恢复策略先排空在途 revision，并以读回确认。
3. 功能候选固定后，测前冻结场景、输入、并发、预热、轮数、样本量、预算、分位算法和失败处理。复用现有正式预算，不事后降低。
4. B0/B1 或服务级对照各用独立 checkout/二进制，在相同环境顺序执行。基点无相同路由时记 not_comparable，不拼接其他批样本。
5. 保存所有样本与失败/超时，不以失败样本未返回为由移出分母；RSS 不可读记 unavailable，不能填 0。
6. 若无真实网关，组件测量继续但服务/端到端状态 blocked；真实网关本轮是否具备拦截能力必须测试，不搬用旧 0.0.83 结论。

### LX07 隔离 PostgreSQL + OIDC 集成（条件任务）

在独立本项目测试环境中，验证真实 JWT 签名、issuer/audience/expiry/JWKS、租户与对象权限、职责分离、审计事务、回滚及服务重启；PostgreSQL 空库迁移回放，并验证生产模式拒绝 SQLite 和 X-Dev-*。本地受控测试 IdP 只能称生产形态集成，不是客户生产验收。不要连接兄弟仓库数据库、企业真实租户或启动新业务架构。环境缺失先交付可复用部署/验证说明与组件负向，条件腿 blocked。

### LX08 托管源与上游能力（条件任务）

只读复核 DNS、证书、重定向和实际 fetch 结果。fake-IP/保留地址仍被挡就记录 blocked；不改 hosts、代理、白名单或 SSRF 规则。条件可用时用固定上游 revision 验证安装、只读更新检查、差异确认、取消、内容漂移拒绝。远端单任务停止/原子执行需要可证实的后端协议；记录版本、返回事实和缺口，不用轮询或本地锁宣称已得到原子保证。不下载执行未验证旧 CLI 来凑“不支持 --wait”样本。
