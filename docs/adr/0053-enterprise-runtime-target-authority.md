# ADR-053：企业运行目标独立授权清单

状态：采用，基础加载、部署预览/执行和回滚门禁已接线；登记体验及真实部署验收待完成。

租户级 policy:manage 只能管理已获准的资源，不能用自行填写 sandbox 名称或客户端 attestation 声明控制面共享网关上的目标归属。采用控制面部署管理员维护的本地精确授权清单，独立于租户 HTTP 请求、Edge 发现和模型输出；不新增全局公开可写的目标登记 API。

每项完整绑定 tenant/environment/asset/instance、连接指纹、网关名称摘要与精确 target。无通配、目录推断、同名匹配或跨租户回退；相同连接和目标只能一项独占分配，共享沙箱另待显式影响与交集语义设计。清单含签发/到期时间，删除、变更或到期在下一次读取时生效，不缓存历史授权。

这是一项部署管理员授权，不是沙箱内角色/Skill 身份的运行时证明，也不是发行签名。控制面文件管理员是信任边界；同服务 UID/管理员可修改文件的风险不由该清单解决。部署时仍需可信 CLI、TLS/握手、源身份、版本/审批/配置读回/执行验证；清单不直接授权业务能力。部署准备在读取目标策略前校验，预览绑定清单摘要，执行前重新探测并重读授权；成功回执记录授权摘要、连接指纹与网关摘要。回滚再次核对当前授权、来源身份及原回执连接，不允许借回滚切换网关。旧回执缺少连接证据时失败关闭。这不消除最后一次检查与外部写入之间的全部竞态，也不替代真实环境验收。
