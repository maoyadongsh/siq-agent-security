# ADR-050：个人客户端生命周期实现方向（原生条件待验）

日期：2026-09-11。状态：**设计提案，尚未实现安装器，也未关闭 UX-002/Q03**。

依据：[原任务书](../personal-experience-lan-team-development-taskbook-20260910-145507.md) D01/D02/D03/D06/D08、UX-002/003/014；现有 [开发规格](../agentshield-dev-spec-v1.md) §2.3、§3.11；[当前状态](../personal-experience-current.md)。这是工程建议，不把建议方案改写为用户原先指定。

## 当前可复用基础

`apps/agentshield` 的 serve/status/pair、管理/决策凭据分权、writer 锁、不可变版本与恢复协议继续复用。`apps/web/src/local` 仍经 Go embed 正式提供，Vite 仅开发使用。`scripts/personal-experience/start-local.py` 是需要 Python/受信本地构建的开发辅助工具，不是已交付的原生安装器，不能计 AC01。

## 首选实现方向

生命周期入口继续放入已有 Go 命令及经评审的内部模块，复用同一二进制，不复制前后端。以系统浏览器打开现有 UI；登录启动与桌面入口使用操作系统用户级机制。托盘如确有必要，只承担打开 UI、真实状态和通知导航，不持有通用管理/决策凭据，不另起决策引擎。当前不引入 Electron/Tauri 或第三方 Go 依赖；这并不取消三系统通知/后台入口需求。

首版按当前 OS 用户运行，默认不要求管理员/root，也不声明同 UID 隔离。Windows 用户任务、macOS 用户 LaunchAgent、Linux 用户服务/桌面启动项是待实机比较的集成候选，**不是已选定且可用的三系统实现**；KIMI-002-NATIVE 须核实可用权限、登录/注销、路径和宿主运行条件，再批准具体平台方案。

## 生命周期状态与约束

1. 安装：明确来源身份、程序摘要/签名验证范围、安装路径与支持组合；排他创建受管理目录，其他用户文件不接管。下载失败与签名缺失分别报告，不能把临时开发签名冒充发行身份。
2. 启动/复用：核验 local-service-health/v1 的产品/协议和本地实例关联，不能只探端口。端口错误不 kill 对方；不能将另一个状态目录的 SIQ 实例误当本实例。该实例关联能力尚需具体实现与测试，不能仅以现有 healthy() 返回 true 宣告具备。
3. 重复启动：沿用单写者 writer 锁，不删除活跃锁、不绕过 CAS。并发安装/启动收敛到一个实例，须真实子进程正负向验证。
4. 管理：复用已实现会话恢复和本地重新配对。身份公钥/产品字符串不是同 UID 防伪证明；deep link 仅带待办 ID，仍由 UI 完成身份与申请状态复核。
5. 停止：关闭浏览器不停止保护。停止/升级为操作者显式操作；提示受影响智能体及 block 拒绝，不能终止未确认归属 PID。尚未存在的生命周期管理 API 不在本 ADR 中当作已实现。
6. 升级/回退：先读取兼容范围、准备独立已校验二进制，确认后协调停止、保存恢复材料、启动并读回；不允许旧写者进入新状态，不复活撤销授权。继续遵守签名对象不可变、单写者和既有恢复协议。
7. 卸载：仅恢复自己可证明归属的配置/启动项，未知用户文件保留。保留/删除本地数据另行确认，不能删除活动锁来“修复卸载”。

## 进入 UX-003 实现前的最小退出条件

按系统列用户级后台机制、需要的权限、配置/卸载归属、路径与编码、重启和故障恢复验证办法；至少在可用系统验证生命周期设计假设。缺少系统保持明确外部验证阻塞，允许独立模块设计继续。会话协议不另起一套；如需新 API/安装记录，先给版本化合同、迁移与负向样例。

本提案未解决 WorkBuddy 原生钩子/最终参数/Skill 身份的真实性，也不自动启用受控启动。需要后者时先给每平台的依据、体验影响和残余风险。ADR-0048 保持未实现；UX-013 原文仍关闭；团队服务仍不启动。
