# ADR-057：企业连接器启动绑定到已核验文件

- 状态：已采纳（OPT-11，2026-10-07）。
- 范围：Edge 受管扫描、已安装能力探测和 Skill 采集；不改变 Connector NDJSON v1 或发行签名格式。

## 决策

受管扫描必须依据本地已确认 Discovery Plan、固定发行公钥、已核验暂存包和计划内 Connector 摘要选择程序，不再使用通用 PATH 查找。缺少/损坏记录、目录不匹配或未选择的 Connector 均拒绝，回执给出重新核验安装计划的操作提示；不自动删除设备身份或重新注册。独立 `run-once` 保留开发用途，但程序须由绝对 `--connector-bin` 或绝对 `SIQ_CONNECTOR_BIN_DIR` 显式指定，不隐式回退 PATH，不把该入口描述成受管制品认证。

Linux 受管启动逐级 NOFOLLOW 打开程序和父目录。父目录归当前 UID 或 root，拒绝组/其他用户可写目录；root 拥有的 sticky 临时祖先允许，但后续目录仍逐级核验。程序必须当前 UID 拥有、普通单硬链接、0500 权限、ELF、大小不超过 256 MiB。对打开描述符读完整摘要，与已验签计划摘要一致，并复核读取前后的文件元数据。继续持有该描述符，经子进程 fd 3 的 `/proc/self/fd/3` 启动，避免摘要检查后再按路径重开程序。失败不回退路径执行。

该机制抵御 PATH 投毒、外部可写目录和路径替换导致运行另一程序；不抵御可控制同 UID、root、内核或可信 Edge 进程的攻击者。它不声称消除同 UID 的原 inode 改写，也不提供网络/文件系统沙箱。Linux `/proc` 文件描述符执行不可用时明确失败。其他系统的正式企业安装目前不受支持，受管启动明确拒绝；开发显式程序路径仍按既有平台能力运行。跨平台编译和原生验收分列。

受管子进程仅保留 HOME、固定 `/usr/bin:/bin` PATH 和协议所需三项环境变量，不继承设备、模型、管理凭据或动态加载变量。stdout 以分片方式限制单条 NDJSON，超长无换行数据必须在分配无限缓冲之前拒绝；超时、输出限制和关闭状态沿既有协议处理。下游 stderr/错误正文不作为上游错误消息透传。

## 验证与兼容

覆盖安装摘要错误、权限/所有者/链接/父目录、路径投毒、检查后替换、继承环境与无换行输出上限。合法新摘要和明确开发配置须有正向。固定公钥不增加测试逃逸配置，已安装探测仍先验签，再将计划内摘要传给最终启动器。老设备缺少可信安装计划时停止扫描并给出提示，心跳与设备身份保留。Linux、Windows、macOS 的证据按实际执行范围记录，不以交叉编译替代原生验收。
