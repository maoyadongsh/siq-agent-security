# ADR-043：已安装 Skill 的记录入口与内容变化检查

日期：2026-09-11。状态：接受，实施中。承接 [ADR-039](0039-skill-install-publication-recovery.md) 与 [ADR-042](0042-installed-permission-readiness.md)。

现有安装结果绑定在具体操作编号上，目标变化时完整读回拒绝，用户缺少找回记录及了解变化的位置。新增只读安装记录列表和按原签名清单检查当前目标的接口，为 UX-010 更新/移除提供可见基线，不将它们冒充已实现的更新器。

GET `/v1/skill-installations/operations` 返回 catalog/v1。每项 record/v1 含已验签计划、安装声明签名、历史结果及 recorded_status；列表不扫描目标、不验证当前运行状态。无最终结果保留 recovery_required；损坏记录计入 issues，不从未验证正文取名称/路径。最多 64 项、最多读取 256 个状态目录项，越界拒绝，不截断后声称完整。

GET `/v1/skill-installations/operations/{id}/inspection` 返回 inspection/v1，比较原安装清单和当前目标，报告新增、修改、缺失、类型或归属变化。只遍历清单中的目录，未知目录作为一个新增对象，不递归读取；只读取原清单中的普通文件，拒绝链接和特殊文件，不执行内容。文件大小/执行位/摘要和既有硬链接归属分别检查。显示路径转义控制字符并限长，精确路径摘要只用于区分展示记录，接口不接受客户端子路径。

检查总预算为 8192 个观察目录项、原清单字节数最多 64 MiB、单文件最多 8 MiB；最多返回 200 条变化，继续统计已观察变化并标记截断。不能完成时标为 unavailable / comparison_complete=false，保留已观察的部分变化，不将读取失败解释为匹配。目标整体消失标 missing，不等同 SIQ 已完成卸载。无变化只证明检查时目标与原清单及归属一致，不证明来源仍有效、当前权限可用、宿主已加载或实际 Skill 归属。

接口复用安装管理权限、no-store、工作锁和取消/超时预算；不恢复安装、不准备权限、不删除内容、不改写历史记录。前端增加已安装记录入口，可刷新、按原操作返回安装/恢复与权限页，显示检查时间和变化。页面可见时对已选安装每 30 秒只读检查；隐藏时停止自动请求，恢复可见后重新检查。刷新开始及请求失败时撤下旧的当前一致状态。

后续更新/移除必须另行签名计划、明确确认、固定版本、校验受影响实例、失效旧权限并保留未知/修改对象。此 ADR 不授权根据检查结果直接删改用户内容，也不替代更新、卸载、旧版本写入拒绝或跨 OS 验收。
