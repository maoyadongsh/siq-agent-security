# ADR-029：个人实例身份的安装与管理整合

- 日期：2026-09-10；状态：Linux Hermes 实例安装与界面已验证，完整跨平台范围继续实施；对应 UX-006、007、012。

复用 ADR-022 文件事务、ADR-023 实例定位与 ADR-028 发行身份，不引入新服务。安装请求只可选择已发行且当前有效、属于目标实例的身份。服务从签名记录派生主体和凭据路径，客户端不能提交任意路径或密钥。安装计划 v3 显式绑定 runtime_identity_id，应用请求必须匹配；旧 v1/v2 保持兼容。

安装归属记录保存身份引用。修复已管理实例时默认保留身份，不能回落到全局 token。遇到未归属的 managed 配置，没有明确选择时拒绝覆盖。预览读取身份元数据与撤销记录的存在状态作为不可变输入，不读取客户端秘密，不将凭据复制进恢复日志；应用前由服务重查签名身份/Grant。撤销后不能用旧预览继续安装。文件变化、配置应用和授权有效性分别显示，不把配置成功提升为 runtime verified。

配置诊断识别身份、实例、主体、凭据引用、服务和模式是否一致；此检查不读取秘密或代替运行证明。真实自检仍使用自己的临时主体和短期凭据，保护的对象是所选 profile 的原生钩子链路；普通实例授权通过日常会话独立校验。

卸载已管理实例时，先追加撤销身份，再移除配置；撤销不能被文件事务回滚撤销。若配置卸载失败，保留失效身份与文件恢复线索，界面应提示授权已停用、配置待恢复，不声称全部成功。用户可重新签发身份并接入；不复活旧凭据。卸载不删除身份或审计历史。

管理界面将已发现实例与其权限/身份对应，优先重用已发行身份，提供确认后启用与停用操作。取消预览不改宿主文件；先前已发行的未配置身份仍可继续接入或撤销。实际 Skill 加载归属与多平台支持不由此整合推定。

## 实施与验证边界

设置/运行绑定页复用接入弹窗，默认“配置实例权限并接入”，保留仅配置连接组件的兼容入口。权限编辑共用既有待批准编辑器，一次仅显示一个模态窗口；批准固定当前可见版本，冲突必须刷新并重新确认。单次会话期限提供 1/8/24 小时（默认 8 小时），不会延长所选 Grant 本身期限。安装进行时禁用实例切换、权限操作和关闭；已签发身份在取消预览后仍可重用或撤销。权限摘要明确文件只读/读写，不将事实声明当作运行有效。

文件事务包只固定公开身份元数据、撤销状态和宿主配置，不验证签名或读取秘密；管理服务在预览/应用时调用身份核心验证 Grant、签名和实例归属。直接 CLI 不能删除仍有效身份的接入组件；目前需先经管理界面/API 撤销，再明确选择实例卸载，CLI 一体化身份管理继续实施。Hermes 原生命令的 YAML 格式变化不作为卸载失败；核对原登记语义和无关设置保留。

M13 的 Go 正负向、106 项跨语言合同、真实 Chromium（12 项）、公开 Hermes CLI（15 项）及候选制品关系见 [验证记录](../evidence/personal-experience/managed-instance-20260910/verification.json)。这不是三系统三平台综合验收，也不证明实际 Skill 版本归属、当前用户所有会话受控或操作系统隔离。
