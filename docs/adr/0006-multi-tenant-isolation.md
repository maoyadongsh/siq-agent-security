# ADR-006：多租户数据隔离

- 状态：**已采纳（暂行）**
- 日期：2026-08-13

## 决策

- 所有租户实体含 `tenant_id`，外键与唯一约束尽量含租户边界；
- tenant_id 只从验证身份派生，客户端不可覆盖；
- 对象级端点"先租户定位（404）再权限（403）"：跨租户 ID 猜测与不存在不可区分；
- SaaS 阶段加 PostgreSQL RLS 纵深防御（当前单体已预留 tenant 谓词）；
- 证据加密采用 per-tenant KEK（Phase 1 接入对象存储时落地；当前无 payload 上传）。

## 后果

- 正：租户隔离负向测试从第一张表建成就跑（21 项测试含 5 项跨租户负向）。
- 负：所有查询必须带租户谓词，服务层约定需持续 code review 守护。
