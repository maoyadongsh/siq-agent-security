# ADR-034：个人 Skill 导入审阅与恢复

状态：实施中；承接 ADR-033，属于 UX-009/012 增量，完整链接获取、权限批准与平台安装仍需继续实现。

## 历史查询

新增只读管理 `GET /v1/skill-imports`，返回 `local-skill-import-list/v1`。列表最多 64 条，只读取并验签最终发布的导入记录和其清单摘要，不扫描载荷或重新读取原目录。每项标明 metadata_verified/unavailable，payload_status 固定 unchecked；摘要仅含签名时间、来源类型、操作者、制品摘要、文件数量和总字节。损坏记录保留合法记录 ID 与 unavailable，其他未经验证字段不展示；单条损坏不隐藏其余记录。非法记录文件名或目录总条目超过 128 时列表失败；暂存 `.import-*` 不作为发布结果。有效记录按时间倒序，再按 ID 排序，损坏项最后。

复用导入单并发限制与取消预算。列表不能证明当前载荷仍一致；详情 GET 沿用完整内容校验，始终不产生安装或授权。元数据解析/验签由 List 与 Load 共用，后者保留原有载荷和分析完整性验证。

## 前端旅程

个人治理导航和资产页提供“导入 Skill”入口，独立页面按需加载。首批填写本机目录或 ZIP 绝对路径与操作者；当前本机路径入口不伪装为浏览器目录选择或远端 URL 获取。明确显示先导入检查，候选尚未安装。页面展示准入结论、声明的权限需求、发现项和可展开的文件清单/摘要；所有包名称、规则位置和资源均视为不可信文本，不执行或解释 HTML/Markdown。

提交前随机生成 si-ID，URL 只保留 ID，不保存本机路径或操作者。内存保留原创建请求；请求中断后提供“查询导入结果”和使用完全相同请求的显式重试。刷新后凭 URL 查询已发布候选，历史列表帮助找回记录；未发布时明确未找到，不自动导入。新操作由显式“开始新的导入”重置；禁止重复点击生成多个请求。操作中的表单不可修改，离开或退出后取消请求并丢弃迟到结果。取消不承诺发布回滚，依旧按 ID 查询。

列表与详情依次读取，避免同 daemon 导入限流发生自冲突。前端导入请求预算 70 秒，容纳后端 60 秒处理与写入窗口；保留既有其他 API 的超时。外部取消信号与超时共同约束 fetch。错误使用可恢复的中文说明；断连/版本不兼容/限流/完整性失败不能继续显示旧候选为已验证。签名元数据的列表不显示绿色保护标记，打开详情再校验完整副本。

## 验证范围

Go 覆盖列表排序、只校验元数据的边界、单条损坏、超限、取消、权限分权和列表不变更原文件；共享输出样例由 Python 合同验证。浏览器使用隔离真实 daemon 检查本地目录/ZIP、恶意文本、重试、中断恢复、历史、篡改、并发点击、离开/退出与桌面/窄屏布局。浏览器测试不代替原生平台安装，Windows/macOS 交叉构建不作为实机支持。

固定导入的 source.locator 是不透明的 `skill-import:si-…`，不是源目录名称。准入新增仅内部使用的 SourceIsOpaque 选项，固定导入显式设置后不进行“名称与来源目录不同”的信息级比较；默认调用仍保留原检查。其他静态检查、权限事实和隔离决策不变；不会把导入编号误当目录名制造提示。历史准入保留原签名和原结论，不回写。
