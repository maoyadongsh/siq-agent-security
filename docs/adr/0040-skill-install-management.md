# ADR-040：个人 Skill 安装确认与恢复入口

状态：管理 API 与个人确认/恢复界面已实现并通过隔离 Linux 浏览器验证，承接 ADR-037–039。原生平台识别、运行保护和跨系统验收仍待完成。

安装预览已绑定来源和批准权限；本批将现有文件事务接入管理 API 和个人界面。API、状态和界面语义见 [开发规格](../agentshield-dev-spec-v1.md#安装确认与恢复管理入口adr-040)。不扩展任意路径写入，不执行 Skill，不改变已批准 Grant。

安装提交必须明确确认原计划 ID、签名和操作者。URL 只保存不透明操作 ID 与授权定位，不保存 token、签名或内容。读取操作采用签名 claim 内历史计划，不调用要求目标不存在的预览 Load。这样成功安装后刷新仍能查看，授权撤销、候选损坏后仍能恢复失败操作。view 的 plan.installed=false 是原预览历史字段；当前结果以 view.status 和 operation 为准。

HTTP 200 表示取得可验证的操作状态，不等于安装成功。成功安装的 ReadOperation 完整重读目标；内容不一致时返回错误，前端撤下成功状态。失败结果按 rolled_back/recovery_required 展示，结果缺失只返回无签名的恢复需求投影。未知或修改过的用户对象不删除，恢复不能作为成功安装的卸载入口。

验证需覆盖管理分权、严格确认、重复请求、刷新无写入、响应丢失、取消、撤权、目标变化、失败恢复及用户内容保留。浏览器使用隔离 daemon 与合成 profile，真实宿主识别与跨 OS 验收另记，不用接口或 UI 测试替代。


## 本批验证范围

[验证记录](../evidence/personal-experience/skill-install-management-20260911/verification.json)包含真实隔离 daemon 的管理接口、目标文件读写、显式确认、真实提交后丢弃响应、刷新无重复写入、目标变化撤下旧成功状态、撤权与源损坏后的恢复，以及用户文件冲突。浏览器恢复用例在隔离测试状态中删除最终结果来构造中断状态；真实 Go 子进程退出窗口由 ADR-039 的核心测试覆盖，两者不混称。未执行候选代码或原生宿主，没有改动用户日常配置与服务。

窄屏确认框单独限制尺寸，来源摘要与授权记录默认折叠，恢复按钮与确认选项可见；详情展开仍做宽度检查。提交进行中禁用结果操作，离开取消请求，原结果仍可按不透明操作 ID 查询。安装权限未提升为 deployed/effective；成功读回表示当前文件匹配原清单，不代表宿主或 OS 已强制权限。
