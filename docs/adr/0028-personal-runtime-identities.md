# ADR-028：个人实例凭据与自动会话接入

- 日期：2026-09-10；状态：核心、HTTP 与 Hermes 钩子已实现，正式安装/界面整合仍进行中；对应 UX-003、006、007、012。

现有适配器共用全局决策凭据，agent_id 来自配置或环境；这不足以隔离不同实例的网络 API 权限。M10 已支持固定 Grant，但普通用户不应手工创建 Intent 或填入宿主 session ID。

新增本地实例凭据：管理端选择已发现的 Hermes 实例、已批准部署的 Grant、精确 Grant revision、操作者和会话期限。实例的运行主体使用保留命名空间 `hri-<instance hash>`。凭据元数据按随机 identity ID 签名、不可变发布，记录实例、主体、Grant 权限摘要、操作者及期限策略；只存凭据哈希。客户端凭据另存状态目录的 0600 文件，HTTP 不返回秘密正文。签名元数据是发行审计记录；不存在完整元数据的孤立凭据文件不能认证。撤销以签名记录追加，读取损坏或不一致时拒绝。凭据证明持有已登记实例的能力，不构成同 UID 进程隔离或真实 Skill 加载证明。

一个实例同时只允许一个未撤销身份；换授权先撤销旧身份再发行新身份。管理员申请不能隐式扩大或批准 Grant。发行与安装配置应用分开登记，只有实际宿主调用可证明接入；前端启用流程将复用既有接入预览/事务，不把身份发行显示为已保护。

Hermes 插件将真实 hook session_id 交给独立的会话接入端点；服务从凭据派生 platform、agent 和固定 Grant。为会话生成既有 Intent 权限包络并固定 Grant，重试不延长期限，不替换已有绑定。默认会话 8 小时，可配置 60–86400 秒，同时受 Grant 期限约束。包络表示“在用户确认的实例权限内运行”，不声称已获得原平台任务提示词的可信目的；不存储提示词，不赋予 unknown 效果。真正的任务目的和 Skill 加载归属仍需后续原生接入证据。

所有实例凭据的决定、观察和来源端点必须匹配登记的 platform/agent，且 session 已绑定该 identity 派生的 Intent 和 Grant。其他实例凭据、全局决策凭据、管理会话均不能冒用保留主体；JSON 身份字段大小写别名也不能绕过检查。已管理实例的接入/身份不可用始终拒绝，普通资源策略仍遵守 block/warn/audit_only 的既有语义。

运行自检改用既有短期启动凭据认证其正常决定/观察请求，限定正在自检的真实 session 和临时主体；不借用实例或全局凭据。插件凭据只发送到验证过的本机端点，禁止代理转发和重定向。普通旧配置保留其全局凭据兼容；新管理实例配置锁定主体，不允许环境覆盖成别的实例。

本批先实现身份发行/撤销、服务端范围校验、原生会话自动接入和临时 profile 真实 CLI 验证。正式安装事务、前端选择/启用、重启与升级迁移仍需后续整合；不得用 API/夹具完成替代普通用户体验验收。验证覆盖凭据分权、跨实例/跨会话、撤销/重启、错误 Grant、并发接入、不延长、损坏元数据/软链接、泄露防护和原生调用。

M12 将核心接入管理 API、会话登记和六类决策端点。实例凭据只可访问服务端已绑定的主体/会话；自检凭据也限制在活动检查会话，取消或过期立即失去认证能力。管理 API 输出不含 credential_hash 或 token，所有新请求拒绝大小写别名、重复/未知/缺省/null 字段。真实 CLI 证据使用隔离 profile 与生成配置，不能把本批发行状态或脚本配置结果当作正式安装界面完成。旧全局路径仍保留普通主体兼容，可信 Skill 加载归属仍不成立。
