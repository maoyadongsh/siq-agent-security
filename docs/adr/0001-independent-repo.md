# ADR-001：独立仓库与产品边界

- 状态：**已采纳（暂行，待评审会确认）**
- 日期：2026-08-13
- 依据：设计文档 v0.2 §26.2 / §28；开发计划 §1

## 决策

产品以独立 Git 仓库 `siq-agent-security` 交付，SIQ 是首个接入方而非代码宿主：
- 不 import 兄弟仓库内部代码、不查询兄弟仓库数据库；
- SIQ 专属能力放入 `connectors/siq`，经版本化 API/事件接入。

## 后果

- 正：产品边界清晰，可独立发布；防 SIQ 字段耦合。
- 负：跨仓合同（Export Contract）成为 Phase 1 前置依赖（开发计划 D3-D5）。
