# ADR-049：个人平台实测材料与支持声明分离

日期：2026-09-11。状态：本批实现采用；仅离线 QA 合同，非运行时权限设计。

依据 UX-001/AC11；详见 [材料规格](../personal-platform-validation-spec-v1.md)。

已发布的历史证据分别来自源码核查、夹具、CLI 或桌面使用，不能互相替代。K001 恢复 CI 后，仍需将具体平台版本 × OS × CPU × 运行方式与能力逐项关联。

决定：在现有 scripts/personal-experience 和 packages/contracts 内增加标准库验收材料校验器，保留18个候选组合及八项接入能力；没有新增服务、数据库、宿主执行器或授权路径。未经实测的组合不删除；WorkBuddy 不接受 CodeBuddy 替代；校验成功只说明材料格式/身份声明/摘要一致，不为执行真实性背书。

否决：用一个总计通过率掩盖未知组合；将源码检查或交叉构建自动提升为原生通过；旧报告直接改写为当前候选；让工具输出 supported 或修改发布支持矩阵。

影响：后续 Kimi 原生探测可使用同一格式交付，仍需人工审阅；不存在的上游运行形态须另行产品裁决。M0/UX-001 不因本工具 CI 通过而完成。新数据不混入既有签名事实链。
