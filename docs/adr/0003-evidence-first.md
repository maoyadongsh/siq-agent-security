# ADR-003：证据优先与模型非权威原则

- 状态：**已采纳（暂行）**
- 日期：2026-08-13

## 决策

- 每个角色/归属/权限/风险结论必须有 `evidence_ids` 回链；
- 模型输出永远不能成为 `effective` 权限、不能直接纳管或批准（设计文档 §11.2）；
- 模型分类固定 temperature/seed，`classification_run` 保存原始输出，保证"可追溯重跑"；
- 模型不可用时退化为规则 + 人工确认（分类服务 Phase 1 后接入，当前 API 未依赖模型）。

## 后果

- 正：结论可复核、可回归测试。
- 负：人工确认是 MVP 必经路径，吞吐受限（可接受）。
