# ADR-052：企业 OpenShell 显式 CLI 连接诊断

状态：本轮企业自动接入开发采用；真实部署与最小凭据验收未完成。

ENT-012 继续采用既有控制面 CLI + 网关适配器，不新建 HTTP 执行桥、不把策略发布能力交给 Edge。新增诊断入口只复用现有 gateway info/status/version 解析器；固定只读命令白名单、总时间预算和输出上限，禁止策略/沙箱写入。

企业诊断要求受控部署显式配置绝对 CLI 路径和 HTTPS endpoint；禁止环境脚本以及 insecure（包括回环）。冻结传入子进程的白名单环境与 endpoint，连接前后绑定 CLI 文件元数据指纹；不读取证书私钥或运行项目脚本。原个人/历史 CLI 兼容路径不在此变更中被暗中修改。文件元数据指纹不是已签名二进制完整性证明，证书内容同路径替换也未由指纹覆盖。

诊断只报告控制面配置连接，不意味着该网关或其沙箱归属当前环境/租户。环境租户定位先于权限校验，需 env:manage 和 policy:read；不接受用户请求中的 CLI/endpoint/path 参数，不列全网关目标或原始网关名称。冻结上下文、指纹与网关名称摘要仅用于后续一致性核验。

握手、版本观察、配置表达能力与实际执行证据分开；没有部署和 allow/deny 行为验收，ready_for_deployment 始终 false。CLI/网关版本不猜兼容，兼容及最小凭据状态未核验。缺配置、拒绝不安全配置、调用失败、未知版本明确返回；不以连接成功替代运行时绑定、审批、独立读回和防攻击能力。
