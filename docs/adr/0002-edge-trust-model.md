# ADR-002：Control Plane 与 Edge 的连接和信任模型

- 状态：**已采纳（暂行）**
- 日期：2026-08-13

## 决策

- Edge 仅建立出站连接；任务经控制面下发、签名、带租户/环境/范围/过期时间；
- Edge 设备身份经一次性注册码（15 分钟 TTL、只存哈希、单次有效）换取，secret 只返回一次、只存 sha256；
- 吊销即时生效：每次任务领取/心跳在线校验（对应 SIQ IAM 服务主体吊销 ≤15 分钟滞后的教训，本产品不做纯离线验签）；
- **已记录残余风险**：部署回执可信度以 Edge 完整性为上限（设计文档 §21.1 不变量 #5）；Phase 4 评估独立验证组件；
- Edge 侧任务签名验证（Ed25519）为 Phase 0 后续项，当前 Edge 客户端打印警告、控制面记录签名缺失。

## 后果

- 正：注册码防暴力枚举（限流待补）、吊销即时。
- 负：Edge 离线期间无法吊销确认（重连时校验）。
