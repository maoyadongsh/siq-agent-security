# 安全控制台到原业务结果的导航验收

日期：2026-09-24。对应收尾清单第 3 项，解决控制台只有证据编号、无法打开原业务运行的问题。**代码与分段浏览器验证完成，尚未部署到既有服务；不据此关闭生产身份验收。**

## 用户操作

SIQ 智能体详情新增“业务运行结果”，展示记录时间及“查看业务运行结果”，事件编号收在详情中。入口缺失和读取失败有不同提示，可重试。点击在新页面打开业务系统；业务系统用当前登录账号重新核验原运行归属和数据权限，然后进入已有结果页。正文仍由用户点击查看，不因跳转自动读取。

## 实现与边界

- 新增[导航 v1 合同](../../packages/contracts/siq-business-event-navigation.v1.md)，既有事件 v1 和 Go Connector 保持兼容，无数据库迁移。
- Control API 按当前安全租户查资产及关联证据，并检查 `agent:read`。仅 gateway 类型、严格格式的 SIQ 事件定位能生成链接。业务地址来自管理员配置，不接受模型输出 URL 或浏览器传入目标地址。
- 研究业务导出终态事件时，在导出根的 `.navigation` 下写入不可覆盖、0600 的事件→结果摘要索引；不含明文租户、会话、运行或正文。Connector 忽略该隐藏目录。索引失败不隐瞒已保存的安全事件，也不改变运行回收流程。
- 业务解析接口按当前业务租户/用户及结果主键查询，再复用原结果完整性和实时数据授权校验。文件读取有大小上限，拒绝符号链接、非普通文件、宽松权限、重复字段和错误 schema。安全管理员身份不提供业务数据权限。
- 导航不会建立会话、执行任务、生成授权或发布报告。跨账号/跨租户返回 404，撤权等当前权限失效返回 403；缺少旧事件索引不猜测关联。页面错误不显示内部路径或原始服务器错误。链接不传安全凭据，设置 `noopener noreferrer`。

## 接入与回退

管理员在安全控制端配置 `SIQ_AS_BUSINESS_WEB_ORIGINS`，值为“安全租户 ID → 已部署研究 Web origin”的 JSON 对照。示例见 [Control API 环境模板](../../apps/control-api/.env.example)。仅允许 HTTPS，或字面 loopback 地址上的 HTTP；不能填写账号、密码、路径、查询参数或片段。默认空配置，页面明确显示尚未接入，不猜测企业业务地址。

研究侧继续使用原 `SIQ_SECURITY_EXPORT_ENABLED` / `SIQ_SECURITY_EXPORT_ROOT`；新增索引随终态事件产生。没有留存结果或旧事件无索引时，业务端提示暂不可用。上线需两端代码同步到各自部署，新页面不取代原结果接口。

回退时移除业务 origin 配置可关闭入口；恢复前端/API原候选即可，无新增数据库回滚。保留已产生的事件及索引，不修改历史审计；回退后旧版 Connector 继续忽略隐藏索引目录。
