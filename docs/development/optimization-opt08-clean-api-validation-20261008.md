## 修复内容

请求暂存、pending、启动/恢复记录、恢复扫描和宿主监管器统一解析请求所有权目录：优先 `SIQ_RUNTIME_ROOT`，其次 `${SIQ_LOCAL_STATE_ROOT}/var`，未配置时兼容项目内 `var/`。显式空值、相对路径、非规范路径或符号链接被拒绝，不静默回退。

路径解析不自动建立或迁移所有权记录。部署者必须预建 `0700` 私有目录；目录缺失、权限过宽和损坏的所有权记录仍导致恢复不就绪。两个固定监管服务模板和安装器生成的环境文件绑定同一运行态目录，旧模板不匹配时拒绝覆盖；本批没有修改本机已安装服务。

业务提交只包含本次 15 个文件，其余 113 个既有跟踪文件改动保留。迁移、回滚和适用范围见业务仓 `docs/operations/qwen38-request-state-location.md`。这是请求所有权状态修复，策略、快照、公司数据、工具链和解释器等其余部署路径仍须继续核对。
