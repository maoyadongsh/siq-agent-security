# OPT-08 D3s：原生 Skill 上下文管理与精确撤权

日期：2026-10-07。OPT-08 保持 `implementing`，完整任务验收数仍为 **9/16（56.25%）**。

## 1. 问题与实现

真实业务生命周期验收发现，已有原生 v2 SEC Store 支持签名撤权，但公开管理端点仍只处理旧版 v1。通过修改私有状态完成测评，不能证明产品具备可用的管理入口。因此先补齐版本化管理合同和实际 HTTP 接口，再开展真实业务撤权测试。

合同提交 `a3756716`，实现提交 `48bdba45`。规格见 `docs/agentshield-dev-spec-v1.md` 的 D3s 增量；[协议](../../packages/contracts/native-skill-context-management.v1.md)定义：

| 管理操作 | 端点 | 行为 |
| --- | --- | --- |
| 安装／会话历史查询 | `GET /v2/skill-contexts?install_id=…` | 验证签名，有限分页，返回上下文及撤销记录 |
| 精确历史读取 | `GET /v2/skill-contexts/{id}` | 保留原签名字节，历史读取不要求原 Grant 或运行宿主继续有效 |
| 精确撤销 | `POST /v2/skill-contexts/{id}/revoke` | 确认原始签名并先审计，再追加签名墓碑；重复确认返回同一记录 |

三类端点均要求既有管理身份和 loopback／Host／Origin 检查；决策凭据、运行凭据和原生发布凭据不能管理上下文。未新增上下文签发入口，模型文字不能伪造一次真实加载。旧 `/v1/skill-contexts` 的合同保持不变。

查询最多扫描既有 4096 条容量、每页最多 64 条，并设置请求期限及可取消的读锁等待。页游标按不可变 ID 排序，不承诺并发加载期间的快照一致性。损坏状态拒绝，未知／重复参数、控制字符、非规范整数和非法游标均拒绝。

## 3. 候选身份与实际业务验证

Linux arm64 二进制 SHA-256：`4d49184507eaac5ae38a8f5e3a1be4429c753a04713ad68522f556a001738fe1`。

本轮复用 D3p／D3r 的受保护业务镜像与原生制品，但 SIQ 二进制已经改变。新建独立 Authority 并通过公开管理接口批准两项真实业务 Skill；安装与重启身份检查各 8 项通过。不把旧候选全部测试自动继承到新候选。

真实业务 SSE 入口的两个独立请求均已完成，原测评器与独立复核均通过：

| 用例 | 真实调用序列 | 签名记录 | 独立效果 |
| --- | --- | --- | --- |
| v815 正向对照 | 加载写入 Skill → 读取公司元数据 → 写入本请求输出目录 | 三条 allow 回执，读取／写入均带准确的 writer Grant | 文件存在、非符号链接、正文等于预期合成标识 |
| v816 运行中撤权 | 加载同一写入 Skill → 读取成功 → 管理员 HTTP 精确撤销 SEC → 实际尝试写入 | 加载／读取两条 allow 回执；签名 SEC 与签名撤销记录相互绑定 | SSE 记录实际写入尝试和工具错误，目标文件不存在（含符号链接检查） |

v816 的诊断控制器在 `read_file` 完成事件之后读取签名回执，通过公开 v2 查询接口核对当前会话及安装，再提交原签名确认撤权。管理 HTTP 返回后 **6140.288 毫秒**收到写入开始事件，随后收到工具失败事件。时差是本机控制器的单调时钟观察，不冒充跨进程执行时钟或撤权延迟性能指标。

撤权后的写入在生成决策回执前被拒，因此**没有 write_file deny 回执**；本批五条回执全部是 allow。实际防护证据是签名撤销、准确上下文绑定、真实工具尝试及失败、目标文件不存在，以及同候选正向写入成功的组合。SSE 工具错误字段仅是布尔值，不宣称获得了细粒度、带签名的 `skill_context_revoked` 拒绝原因。

撤销后的历史读回保留原上下文；重复提交同一签名返回相同墓碑，提交错误签名得到 409／`skill_context_changed`。未向业务 API、模型或容器提供管理会话，未修改私有签名状态以模拟撤权，未关闭原业务授权和财务证据门禁。

## 4. 边界与剩余工作

历史查询不提供实时 `effective` 授权，撤销不会撤回已完成的外部副作用，也不承诺终止已经进入 handler 的调用。原生 Store 必须在 daemon 启动时完成可信绑定，未绑定返回不可用。

当前提供 HTTP 管理能力；现有 v1 管理页面尚未显示 v2 原生上下文。本批不宣称页面交互完成，也不替代业务并发、安装升级／漂移、网络、租约失效及最终同候选矩阵。
