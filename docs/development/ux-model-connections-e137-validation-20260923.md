# 模型配置发现与连接检查链路验收

日期：2026-09-23。接续 E136，为 UX-03 的模型发现部分交付；整体目标保持 `active`。

## 用户可见结果

首页与运行环境页新增“已有模型配置”。自动读取已发现 Hermes 实例中的显式模型声明，以及 OpenClaw 默认模型、备用模型与对应 provider。页面显示来源实例、模型名称、配置用途、服务地址和凭据读取状态，不要求重新输入模型名或 API Key。

“重新发现模型”调用真实后端重新读配置；“检查模型服务”请求所选服务的模型列表，返回是否列出该模型。认证失败、限流、服务异常、连接失败、接口不兼容和未列出模型分别呈现。旧成功提示会被新结果替换；配置变化返回冲突，重新发现后可恢复。页面刷新不复用旧检查结果，观察结果 30 秒后显示过期。

发现时不发网络请求。显式检查不发送提示词、业务内容，不生成回答，不改默认模型，不自动使用备用或云端配置。备用模型仅代表原配置声明；列表可见不能证明推理、余额、实际运行时路由或机密模式可用。

## 实现与真实适配问题

后端新增管理接口 `GET /v1/model-connections`、`POST /v1/model-connections/check`，使用独立版本化合同。请求只能提交发现对象 ID 和不透明指纹，不能提交任意 URL、凭据或命令。指纹用进程私有 HMAC 绑定配置、实例与已解析凭据；检查前后重新读取，配置或凭据更新拒绝旧选择。服务重启后需重新发现。

Hermes 支持直接 `model` 映射中的 default/provider/base_url/api_mode 与明确凭据字段；模型映射重复键、别名、合并与嵌套歧义不会被猜测解析。适配了 PyYAML 常见的顶层无额外缩进 provider 列表，避免其导致正常 model 声明被误判。其他位置仅作为背景配置，不根据相似字段猜测当前路由。

OpenClaw 读取默认和备用模型的 provider 配置，支持内联凭据、显式环境变量 SecretRef，以及已登记 file provider 的 JSON Pointer 凭据引用。真实 Step 配置使用后者，初版因不支持而禁用了按钮；已补齐该适配，再运行真实接口验收。文件读取有大小、类型、归属对象和权限检查，拒绝符号链接、重复 JSON 键、错误指针、宽松私密文件权限及 exec provider。POSIX 使用属主权限约束，Windows 复用已有 ACL 检查，未宣称 Windows 原生验收。

Hermes 明确 key_env 可读取同 profile `.env` 的字面赋值；不执行 dotenv，不推断其他目录继承，不猜同时存在 inline/key_env 的优先级。只在后端读取凭据，不返回密钥、引用文件位置、原配置或服务响应原文，不复制凭据到产品状态。

网络检查仅为 OpenAI 兼容接口的 `GET <base>/models`，6 秒上限、1 MiB 响应上限，不跟随重定向、不使用环境代理、不关闭 TLS 校验。HTTP 仅允许明确本机或私网地址，DNS 解析后再检查目的 IP；拒绝链路本地与指定云元数据地址。配置 URL 的编码路径在请求中保留，防止无意改写服务路由。

## 按钮与前后端验收

| 操作 | 证据 | 结论 |
| --- | --- | --- |
| 自动发现 | 真实本地 API 读取两个框架的临时配置，测试 HTTP 服务调用数保持 0 | 发现不调用模型 |
| Hermes 检查 | 页面选实例 → 管理 API → 有认证的真实 HTTP 请求 → 指定模型列表匹配 | 前后端及出站请求实际贯通；上游列表使用合成测试服务 |
| OpenClaw 检查 | 同一页面选择 OpenClaw 默认配置，读取其独立 provider/凭据 | 未复用其他实例的授权或地址 |

| 失败替换旧成功 | 实际 HTTP 401、429、503，页面显示不同原因；不保留上次成功 | 失败有明确反馈 |

| 刷新与手机端 | 刷新清除旧成功；390px 运行环境页实际点击检查并收到对应结果 | 核心按钮有可用的真实链路 |
