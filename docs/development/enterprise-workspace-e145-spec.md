# 企业组织与角色工作台（E145）

接续 E144，落实 ENT-UX-02 的组织/角色说明与可用入口。复用既有 IAM refresh/login 与内存 access token，不新增密码登录、角色授予或组织切换实现。

新增 GET /api/v1/console-context，console-context/v1：必须经 get_identity；tenant_id/actor_id/identity_type 仅从验证身份；组织名只查本控制面 Tenant 的同一 ID，未同步则 null，不查兄弟仓数据库。已知角色返回固定中文标签及职责摘要，自定义角色只报存在数量。权限为有限路由访问布尔值与有限操作布尔值，依据已有权限点逐一计算，不从角色显示名称推断。不输出 token、JWT 原文、邮箱、其他组织或完整权限列表；GET 不创建记录。认证来源区分开发身份头与已验 token；角色说明不是动态权限的替代。

增加“工作台”作为企业默认首页，展示当前组织、角色、可用操作、联系组织管理员的明确路径，技术标识折叠。侧栏和快速入口共用经后端核对的权限，深链接无权限时显示说明，不渲染对应页面/发起领域请求。设置始终可达，用于查看连接与身份摘要。状态不可读时不沿用旧身份入口；重试只读。未知/不完整合同拒绝。身份上下文只放组件内存；退出登录/认证失效卸载旧上下文，重新登录重新读取。手动刷新位于工作台，无周期刷新打断业务表单。权限是带查询时间的快照，后端每次请求仍复核。

总览需同时具备 agent:read/env:read/policy:read；前后端一致，其他用户从工作台进入已有权限的页面。修复总览“未吊销即在线”与策略计数固定零：在线按有效设备的新鲜心跳计数，策略按本租户真实行数；资产标签明确已确认及已纳管。总览快捷入口也按实际访问权限显示。reviewer 只有 change:approve 而无 policy:read 时不暗授读取权，工作台明确提示需管理员补齐查看变更所需权限。

本批不声称企业所有页面的写按钮已完成角色适配，不改现有角色权限表，也不声称完成生产 IAM 集成验收、负责人目录、角色分配和完整审批工作台。既有新手接入/候选处理路径需保持可用。
