# 企业首次环境接入增量（E143）

2026-09-23，落实 ENT-UX-01；当前实现先覆盖已有可信 Edge/Connector 二进制的环境，不声称已提供下载/自动部署、生产 IAM 或全操作系统原生验收。

## 流程与合同

创建环境只需名称/类型，采用现有 discovery、medium 默认值；唯一名称冲突返回 409，审计/outbox 与创建同事务。回包丢失不自动重建，提示刷新环境列表后从已有环境继续。URL 保存环境 ID，注册码只在组件内存保存，刷新后不恢复、不自动再签发。

新增只读 `GET /api/v1/environments/access` 返回版本化权限布尔值；身份由现有认证派生，不扩权。`GET /api/v1/environments/{id}/onboarding` 先租户范围定位，再 env:read，返回版本化环境、设备数、最近 100 台设备、心跳新鲜度、该环境证据数及最近 20 个扫描任务的候选/证据回执计数。按环境汇总，不从其他设备心跳推断当前设备在线；设备与任务分别展示，截断明确。无注册码、设备 secret/hash/公钥、扫描路径或原文。GET 不写状态。

注册复用一次性码 API。用户确认目标设备可达的控制面根地址后，按 Bash/PowerShell 展示明确的注册/心跳/领取任务命令，不假定浏览器地址自动等于可达地址。新增 Edge `--enrollment-code-stdin` 与原参数互斥，有界读取、不打印输入；已有本地状态拒绝再次注册，避免误覆盖。二进制须由可信部署渠道提供，页面不生成未经验证的下载地址。注册码不嵌入脚本/URL/持久存储，复制由用户显式触发。

扫描复用 `/api/v1/scans`；Hermes/OpenClaw 分别使用已有受限默认 scope，不自动广泛扫描九类系统。不支持的采集器不显示为可用；用户看到范围后显式提交。设备未报告所选采集器或无新鲜心跳时不可提交。注册、心跳、扫描排队/已上传/完成/失败、本次上报对象数独立展示；空扫描不能冒充资产发现。此扫描是环境任务队列，不承诺指定某台设备执行。

不新增自动批准、有效运行时保护或 Edge 吊销（SEC-F04 后续）。连接失败撤下旧进度并允许显式刷新。未知写入结果要求先读回，不自动重复提交。刷新/切环境不得带入其他环境注册码或旧请求响应。

## 验证

合同 Schema + Pydantic 样例；后端 env/tenant/权限负向、设备新鲜度/吊销投影、证据环境隔离、扫描状态/截断、无 secret、GET 无写入；创建同名 409 与事务回滚。
真实 loopback API + 隔离数据库 + 原生 Edge/Connector + 浏览器完成环境创建、注册码、注册、心跳、扫描、上报、刷新恢复与设备状态读回。故障注入单列；开发身份不能冒充生产 IAM。前端测试/双构建、Python全量/ruff、Edge Go 测试/vet/跨编译。无需数据库迁移（只读投影与现有唯一约束错误映射）。回滚仅逆转本批增量，保留原工作树、设备身份、授权和审计。

## 实测阻断修正

原生 Edge 扫描已完成但批次上传失败：`UploadBatch` 的 map 内含 `[]*Candidate` 等 Go 类型，不能直接交给只接收 JSON 值的规范化器。上报先按实际 wire JSON 序列化，再用保留数字字面量的解析器转为 JSON 值后规范签名；签名算法和合同版本不变，不全局改变 CanonicalJSON 的数值语义。新增真实 HTTP 捕获验签、字段篡改拒绝和 Python 验签链验证。地址校验同步 Edge 的 origin-only 合同，拒绝带路径的地址。
