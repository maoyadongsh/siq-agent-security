# E153 运行详情的已采集输出

状态：受控已采集输出接口与页面已验收，原生宿主钩子与正式业务报告继续待办。承接 E152 / UX-11。

界面增加“本次运行的已采集输出”，放在审计折叠区之前。它是授权采集的工具输出，不命名为正式报告、已发布产物或任务完成。列表默认只读元数据；正文必须选定记录后明确确认，使用纯文本呈现；关闭、刷新、切换活动即清除，不入 URL/浏览器持久存储。

GET `/v1/task-activities/{id}/outputs?view=tasks&snapshot=...` 返回版本化有界列表；POST 同一路径的 `/read` 携带版本、准确 record_id、预期正文摘要及 confirm_display=true。二者均使用现有管理认证，绑定验签回执快照。客户端不能提供运行身份/会话/绑定或路径。

服务端从该活动的完整历史绑定（platform/session/agent/task/intent/digest）验证签名 binding、intent 和 runtime identity 唯一对应，再使用 E152 的精确来源筛选。此查询仅供历史内容管理，不授予新的执行权；运行身份或授权后来撤销，不删除其历史输出，保留期和原文仓当前完整性/启用状态仍须核对。来源无法确定给出 unattributed，不能回退到 task-only 列表。输出默认最多 4096 条，前端分批展示。

响应状态区分 disabled / unattributed / ready（含真正空列表）；无权限、快照过时、损坏、缺失、到期或内容摘要不一致均明确拒绝。读取前后核对活动快照，正文不随列表自动取得；所有响应 no-store，禁止 GET 读取正文。

验证包含真实管理/运行时 API 采集→元数据→显式读取→刷新清除的浏览器流程及窄屏，跨活动/跨身份拒绝、旧 task-only 记录排除、权限、过期/删除、损坏/快照变化、迟到响应不显示旧正文。内容查看不取代业务系统权限，不新增自动采集或任意文件读取。
