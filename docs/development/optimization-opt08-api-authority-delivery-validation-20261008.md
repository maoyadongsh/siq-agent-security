## 2. 权限能力及修复

机密数据访问同时要求有效账户、业务查看权限、匹配的token版本，以及未撤销、未过期的精确业务grant。授权范围绑定租户、项目、公司、市场与对象范围。运行租约进一步绑定API所有者、数据库行、请求ID、pool generation与用户；独立业务授权查询前后再次检查运行归属，接管后不能继续使用旧执行身份。

本轮新增反例证明并修复：

- **账户／grant缓存**：另一数据库连接已提交账户停用、token版本更新或grant期限缩短，复用会话仍可能读取旧ORM对象。同步、异步共6个反例；在线查询现明确刷新已有对象。
- **租约缓存**：另一连接已使运行租约到期，旧对象仍可能被续期或绑定到新执行。同步、异步的renew／bind共4个反例；加锁查询保留行锁并刷新对象。
- **到期瞬间**：原授权快照在恰好到期时仍通过。1个反例确认，时间窗口现为 `issued_at <= now < expires_at`。

以上11项反例均在修复前失败、修复后通过。没有移除身份谓词、业务授权、行锁或审计规则。Qwen执行租约上限120秒属于现有配置，不解释为全部在途工具的撤权时延承诺；ORM刷新也不保证查询结束后不存在并发授权变化。
