## 交付目标

当前产品主线收敛为：**发现框架 → 查看角色 → 查看 Skill → 管理所选对象的权限 → 查看运行记录与结果**。优先做通这条链路，其他功能不抢占默认入口。沿用国内常规管理软件的列表、筛选、详情和明确操作反馈，不使用无法由后端事实支持的概览或能力宣传。

### 对象与术语边界

| 用户看到的对象 | 可靠依据 | 不可混淆的含义 |
| --- | --- | --- |
| 智能体框架 | 明确的框架配置及角色配置中的所属框架，例如 Hermes、OpenClaw；同一框架汇总配置记录数 | 检测到文件不能称为已连接或受保护；可进入角色列表查看各实例，不从单个 Skill 推断安装 |
| 智能体角色 | Hermes profile、OpenClaw agent 等明确配置 | 不把框架安装、Skill 或同名目录当作角色 |
| Skill | 实际发现的 Skill 安装目录及内容版本 | 同名不同位置分别管理；配置关联不等于已运行，检查通过不等于已授权 |
| 权限 | 后端授权主体、范围、版本、状态及实际执行读回 | 不用角色显示名称猜主体；编辑保存、批准、下发、实际生效分别说明 |
| 运行记录 | 可信关联的运行、会话、主体及状态 | 未建立可信关联时不展示“该角色全部运行”；无记录不说未运行 |
| 运行结果 | 同一次运行的实际输出、产物与核验结果 | 成功、失败、取消、待核验明确区分；仅有回执不冒充业务结果 |

### 操作必须真实可用

用户 2026-09-23 补充要求：**按钮必须完成真实前后端链路，不以设计稿、可点击、请求 200 或模拟接口作为完成。** 每项操作至少保留实际请求、后端执行结果、持久状态独立读回与刷新后一致性的验收证据。修改权限还需验证旧权限失效与后续执行结果；连接配置成功仍不能声称原生插件或沙箱已生效。

| 操作 | 必须核验的结果 | 必须覆盖的失败行为 |
| --- | --- | --- |
| 自动发现／重新发现 | 后端完成扫描，分类及数量对应真实清单，来源可追溯 | 不可读目录、扫描并发、部分成功；可重试，不静默当空列表 |
| 选择实例／应用接入 | 原实例 ID 不变；预览摘要匹配写入文件；刷新后诊断一致；其他实例不变 | 预览过期或配置变化拒绝；重新预览后恢复；取消不写入 |
| Skill 安全检查／查看详情 | 检查结果持久化；刷新仍能查到；详情指向同一安装 | 重复点击不重复提交；失败原因可见，不能藏在折叠的高级操作中 |
| 保存权限／批准／接入／停用 | 保存保持待批准；批准与应用后读回；身份绑定正确对象；停用持久化并实际阻断后续工具 | 修改冲突、批准失败、身份失效、响应丢失；不得用按钮状态替代服务端拒绝 |
| 运行记录／查看结果 | 列表、筛选、详情、输出引用都属于同一次运行；刷新保持所选对象 | 无权、产物缺失、未完成、失败／取消状态清楚，不呈现虚假成功 |
| 企业设备接入／审批 | 真实注册、心跳、资产上报；批准对象与执行回执一致 | 跨组织拒绝、设备离线、凭据过期、审批冲突可处理 |

以上逐项记录“已验证／仅部分验证／未验证”。未接通的操作不能呈现成正常可用按钮；不适用或不可操作时说明具体原因。浏览器测试使用真实候选服务与隔离合成数据，不改用户业务配置；原生运行验证、安装发行包验证另列，不能用组件安装测试替代。

用户不必先理解 adapter、runtime identity、grant、relay、doctor 或配置文件路径，便能完成第一次有效使用。产品自动识别能可靠判断的信息，给出推荐操作，并把技术详情放在可展开的区域。需要用户决定的是业务目的、保护范围和有后果的操作；环境探测、状态同步、配置生成与结果核对由产品完成。

个人首次旅程：安装并打开 → 自动发现已有环境 → 选择实例与保护范围 → 应用配置 → 完成一次工具验证 → 看见结果及下一步。

企业首次旅程：登录组织 → 创建环境 → 在目标设备完成接入 → 看到设备与资产 → 分配操作员/审批人 → 完成一次审批及执行读回。管理员、操作员、审批人、只读审计员各有自己的首页和待办，不要求所有人学习整个后台。

## 默认行为和信息层级

1. 首页优先呈现“当前可接入什么”和“下一步做什么”，统计、底层证据和配置细节放在后面。
2. 自动发现只读取明确的默认位置和已登记范围，不遍历全部磁盘、不执行扫描到的脚本。多实例明确展示，不能因方便而把接入写到错误 profile。
3. 使用现有模型配置及 secret 引用，不把密钥复制到浏览器、日志或导出文件。未配置时提供一个明确入口。模型连接失败与余额/认证失败分开解释；企业机密模式不会因“一键修复”转用云模型。
4. 将发现、连接配置、实际验证分别显示为用户可理解的状态，例如“已发现”“连接待配置”“已连接，待验证”“验证通过”“需要处理”。范围以真实读回为准。
5. 保留重要批准，但将批准对象、范围和影响集中到一个可审阅步骤。重试复用原事务身份，不把失败操作再执行一遍。
6. 统一中文术语，英文协议名、哈希和内部对象 ID 放在技术详情。首次帮助短而具体，已熟悉用户可以跳过说明。
7. 继续使用当前 SIQ 配色、字体与组件体系；不为引导页引入新的设计风格或大型依赖。动效用于反馈状态，支持减少动画。
