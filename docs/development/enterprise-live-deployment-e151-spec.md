# E151 真实沙箱部署与行为验收

状态：本批限定范围验收完成，见 [E151 验收](ux-openshell-live-deployment-e151-validation-20260923.md)。承接 E150；不能用 fake 回执替代真实执行证据。

使用已有专用验证网关 siq-openshell-scope-validation（HTTPS loopback 17771），创建唯一批次临时沙箱。使用现有基础镜像、限制 CPU/内存、不请求 GPU、不挂载业务目录、不附加 Provider 或转发模型密钥。CLI 的 HOME/config/cache/data 与新沙箱令牌保存在隔离临时目录，仅复用既有网关证书引用；不得变更原默认网关或现有业务沙箱。

在隔离控制面通过真实登记、不同账号审批、预览、持久提交、独立结果读取完成策略变更。对专用沙箱测试网络允许/拒绝，禁止把进程报错或服务本来不可用当成网络策略有效。先获得真实允许成功，再撤销相同目标并验证拒绝，必要时恢复允许进行对照；测试只发送合成公开探针，不读取业务数据。

部署/回滚/策略版本与完整摘要绑定；若执行或回执异常，保留 unknown/failed，不重放旧请求。原策略保护边界与未知字段必须保留。真实配置读回仍标 readback_verified；外部行为探针另记证据，不修改现有 API 为 enforcement_verified。

临时沙箱在 finally 中按本批随机唯一名称回收，确认删除；只清理本批自有对象，绝不按前缀批量删除。执行前后核对原网关登记及其他沙箱，保留命令元信息/摘要和脱敏日志。创建失败也检查是否已有副作用再清理；不得因 CLI 报错推测未创建。

若真实环境暴露适配缺陷，先补规格与负向测试，再修复实际产品路径；不能用直接 docker exec、旁路 policy set 或成功桩冒充控制面部署链。初始沙箱创建策略属于测试准备，不算产品部署成功。

现场缺陷：删除最后一条网络允许规则时，网关返回的完整策略会省略空 `network_policies`；Python/Go writer 却对包含 `{}` 的文档计算预期摘要，导致实际撤销已执行但读回被报失败。修复仅限写入空网络意图时删除该字段，匹配网关无允许规则的序列化形式；不改观察摘要算法，不忽略其他字段差异。新增模拟真实省略行为的正向/负向测试，验证完整静态策略不变、真实撤销可读回、额外策略改动仍拒绝。

浏览器验收增量：允许/撤销两次部署由真实 Web 的“部署 → 预览 → 勾选确认 → 确认并部署”按钮触发，页面走隔离 loopback 开发控制面与真实 OpenShell CLI，不拦截或伪造响应。只为测试请求注入固定开发身份；审批由另一个账号通过服务端检查。保留桌面/窄屏预览与结果截图、捕获本次提交用于同键只读重放验证；每次仅一个浏览器 POST。使用已有 E150 Web 制品并记录文件摘要。拒绝探针必须确认 shell/curl 已完成且返回 403，不能把超时、DNS/连接错误当成拒绝成功。

E151 兼容边界：当前已为空（省略字段或显式空 map）时保留原完整文档并返回 no-op，不为序列化差异执行无意义写入；只有实际撤销非空规则才省略空网络字段。两种空形式均需证明零 set、摘要/版本不变。
