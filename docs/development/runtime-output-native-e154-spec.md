# E154 Hermes 原生输出到运行详情

承接 E152/E153 与 UX-11。本批以隔离配置启动真实 Hermes 0.21 插件加载器和工具分派器，验证原生 pre/post hook → 本地授权采集 → 精确运行来源 → 页面显式查看。工具请求及文件为合成测试数据，不调用模型，不声称完成自然语言任务或正式报告发布。

使用管理 API 预览/安装适配器、签发运行身份及最小只读权限；不直接调用采集接口，不注入成功响应，不替换钩子。先原生执行建立会话，确认默认不保存；启用原文仓及该任务输出授权后再次原生读文件。第二会话未授权时不保存，越权写文件须被拒且目标不存在。

浏览器只列出该运行的输出，确认后才读正文；关闭/刷新清除。重启守护进程后仍能核验历史来源和读取保留内容。记录真实 CLI/分派器/适配器/候选摘要与脱敏检查结果，保留失败证据；不读取或改写用户业务配置、文件及已安装版本。若发现产品缺陷，先补负向测试再修复；不扩大到后续 SEC 清单。

现场发现 Hermes read_file 返回 JSON 字符串又被采集层编码，默认页面出现多层转义，不便阅读。本批增加仅供显示的正文提取：只对 Hermes、唯一 read_file 工具字段和唯一 /tool/result 字段、已知完整返回结构提取 content；最多解码两层、64 Ki 字符，未知字段/错误/二进制/格式异常均保持原始字段。已知格式前置“读取文件的输出”，保留工具行号、截断提示和“查看采集字段”折叠区；原字段字节不变、显示永远纯文本，不新增网络读取、权限、自动采集或正式报告状态。新增格式兼容负向测试，并以最终构建重新执行原生与已有输出浏览器验收。
