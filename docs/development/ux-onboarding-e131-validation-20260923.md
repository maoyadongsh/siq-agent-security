# 首次接入与核心操作验收记录

日期：2026-09-23。对应 [体验任务书](user-experience-onboarding-taskbook-20260923.md)。当前为本地候选代码及候选程序，未升级用户已安装的发行版，未重启既有服务。

## 实际交付

首页自动发现默认环境，直接选择 Hermes/OpenClaw 实例进入接入。资产页将框架、角色、Skill 分开：框架依据明确配置汇总，Hermes 仅有 profile 记录时也能正确出现；查看角色保留框架筛选，刷新不丢失。资产页折叠实例接入区，将日常对象列表放在主要区域。

Skill 检查按钮调用真实后端并保存结果；检查中阻止重复提交，反馈和错误不再藏入高级操作。每行提供详情入口，权限链接仅引用后端授权主体；已签发的实例身份可直接打开对应运行记录。修复弹窗加载期间焦点反复重置、关闭后未返回触发按钮的问题。

## 验收方法与结果

使用 Playwright Chromium 点击由候选 Go 程序内嵌并提供的实际前端。真实 loopback HTTP、真实临时状态存储和真实适配器安装事务；无前端接口 mock。所有配置、Skill、授权、文件内容均为隔离 HOME 内的合成夹具。用独立管理 API 和文件摘要核对浏览器操作结果。

最终 `browser-v9`：**36 项检查通过**。前端 **35 个测试文件、243 项测试通过**，TypeScript 与本地嵌入构建、候选 Go 编译、证明脚本 Ruff 和差异检查通过。测试数彼此不累加。源码、程序、日志及截图摘要见 [E131 脱敏证据](../evidence/flagship-optimization-20260921/ux-onboarding-e131.json)。

| 操作 | 已验证的实际链路 | 限制 |
| --- | --- | --- |
| 首次发现／重新发现 | 首次自动扫描一次，默认无需路径；显式重扫调用后端；读取 Hermes/OpenClaw 实例 | 未覆盖所有不可读目录及多标签页故障 |

## 测试中修复与保留的失败

- `browser-v2` 实际暴露弹窗焦点恢复失败，修复回调变化引起的重复焦点处理及触发按钮禁用问题，后续验证通过。
- `browser-v4` 的文件核对没有解析后端展示路径 `~/…`，测试失败。改为按隔离 HOME 解析后逐项核对，不放宽文件隔离或摘要断言。
- 框架分类初稿只看 `platform_config`，漏掉只产出 profile 记录的 Hermes。修正为明确配置来源汇总，并加入正负单测与浏览器框架→角色验证。
- 历次工具输出及已有私有测试目录保留；最新结果不覆盖旧失败。只有最终同候选复验作为本批通过依据。

## 复验入口

先在 `apps/web` 执行 `npm run build:local`；再在 `apps/agentshield` 编译一个独立候选程序。证明脚本要求 Python 可用 Playwright 与 Chromium；使用新的输出目录，脚本会创建并清理自己的临时 HOME 和守护进程，不启动真实 Hermes，不请求模型。

```bash
python scripts/personal-experience/environment-onboarding-browser-smoke.py \
  --binary var/flagship/ux-e131/siq-agent-security-v9 \
  --out-dir var/flagship/ux-e131/browser-next
```

后续优先补 OpenClaw 权限全流程同候选验证、权限表单与运行结果简化、原生宿主首次可用和发行包体验；企业设备注册与组织权限按独立真实后端旅程验收，不把现有页面或示例数据算为完成。
