# E148 部署预览与提交重验

状态：本批候选实现与验收完成；真实 OpenShell 握手未通过，生产部署不记完成。接续 E147 / ENT-UX-04；保留原授权、Hermes 基线与 SEC-F 后续顺序。

新增 versioned preview/submit 合同。用户选择已批准变更、执行环境和登记绑定后先请求预览，明确策略、目标、后端、动作及当前 revision；取消不写入。预览复用实际部署的权限、批准态、环境、绑定、隔离、selector、编译/校验和 OpenShell live plan 检查，不调用 apply、不写部署或审计。

提交重新运行相同检查并重新生成预览摘要；身份、策略、批准状态、目标绑定、环境、后端身份或 live revision/digest 变化拒绝，要求重新预览。真正执行沿用既有 apply 的 revision/digest 检查和同事务审计。审计追加 preview_digest，不记录配置内容。旧 POST /deployments 保持兼容；新 UI 不绕过预览。

摘要绑定完整控制面策略与审批参数、环境及绑定、编译制品哈希、计划的目标/类型/revision/base digest，以及 OpenShell 握手网关与调用指纹。新 OpenShell 预览要求稳定 endpoint_fingerprint；无法稳定标识网关时说明不能确认部署目标，不使用脚本文件名或版本号代替身份。fake 只在开发模式生成下发任务，明确不代表执行生效。

API 对选定变更、环境和绑定先租户定位再检查写权限；新预览/提交额外要求 policy:read、env:read。修正配置执行后端与登记绑定后端不一致仍可提交的问题。预览 DTO 仅有界元信息与摘要，不包含原始策略、凭据或自由格式错误。前端失败原因使用稳定中文映射，预览失败不能提交；提交响应丢失沿用 E147 待核对路径，不自动重放。

本批不是持久部署意图/重试协议，不宣称跨客户端 exactly-once。数据库读与执行端之间仍依赖现有运行时绑定及 revision/CAS 检查；不能扩大为所有并发撤权窗口已消除。完整差异说明、持久提交恢复、生产并发和部署后的真实行为核验继续。

验收：合同样例、预览无写入、旧接口兼容、同对象身份隔离、改变目标/策略/批准态/绑定/后端/live revision 后旧摘要拒绝、取消不写、真实 API 浏览器预览→确认→部署读回、明确错误恢复、响应丢失不重复提交、两框架及既有审批回归。

实现与验收见 [E148 记录](ux-enterprise-deployment-preview-e148-validation-20260923.md)。前端 HTTP 错误读取只接受有界稳定机器码，禁止将自由诊断内容作为展示文案。
