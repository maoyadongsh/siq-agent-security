# OpenShell 环境发现与策略读取链路验收

日期：2026-09-23。接续 E135，属于 UX-03 统一环境识别的部分交付。整体目标保持 `active`。

## 用户可以完成的操作

首页和运行环境页自动读取已有 OpenShell 配置，展示 CLI 来源、版本、网关、检查时间和真实沙箱列表。用户从列表选择沙箱，点击“读取当前策略”，取得该沙箱的策略版本与摘要，无需手工输入沙箱名称。核对信息默认折叠。

“重新发现 OpenShell”会重新调用后端；读取失败清除旧成功结果并提供重试入口。策略观察超过 15 秒显示已过期，刷新页面重新发现，不恢复旧成功提示。缺少 OpenShell 属可选能力未配置；列表读取失败、协议不兼容和空清单分别展示。

这批只交付已有配置下的发现和只读核对，不创建沙箱、不下发策略、不授予权限。网关可达、沙箱就绪、策略可读与实际隔离效果分开表述。当前仍需服务能够找到正确的 CLI/网关配置；跨项目配置自动导入、多网关选择和模型服务识别尚未完成。

## 前后端与原生适配

新增管理接口 `GET /v1/openshell/targets` 与只读 `POST /v1/openshell/targets/inspect`，各有独立版本化请求/响应合同。前端点击经过管理会话认证，后端真实调用 OpenShell CLI；验证程序没有替换 HTTP 响应。

沙箱目录来自 `sandbox list --limit 1000 --output json`。校验唯一 UUID、名称、版本与完整 JSON，不使用 Docker 名称推测归属，不把失败当作空列表。达到 1000 项即不宣称完整清单。读取策略前后重新核对 UUID、名称、端点指纹和当前策略版本，拒绝重建、配置变化与未知目标；任意命令参数不能经此接口传入。PATH 或脚本未固定端点时只展示发现结果，不开放指定目标策略核对。

现场默认 PATH 中 OpenShell 为 0.0.13，研究项目固定工具链为 0.0.83。项目网关采用已有 mTLS 注册配置：只提供 endpoint 会丢失认证上下文。新增可选 `SIQ_AS_OPENSHELL_GATEWAY_NAME`，与显式 CLI、endpoint 配合，让原生 CLI 使用已注册网关的认证材料；名称及 HOME/XDG 配置位置加入调用指纹。没有复制私钥或关闭 TLS 校验，也没有修改原网关配置。

两轮早期浏览器验收中，目录读取成功，但首页自动目录扫描完成后刷新 OpenShell 区块，取消了正在读取策略的请求。已将两个刷新流程分开；显式整页刷新仍取消旧请求并防止旧响应覆盖新状态。最终增加受控 2 秒读取延迟，在策略请求发出后同时重新扫描智能体目录，证明该流程不再中断策略读回。

## 按钮及结果验收

| 操作 | 实际验证 | 结果边界 |
| --- | --- | --- |
| 自动发现、选择沙箱 | 现有主网关真实返回 2 个沙箱，页面列表与 API 一致 | 当前已配置网关，不代表所有网关 |
| 读取当前策略 | 页面选择精确 UUID，后端原生 `policy get --full`，返回版本/摘要 | 策略读回，不是隔离行为证明 |
| 扫描时读取 | 读取期间重新扫描智能体目录，仍收到 200 与同一目标结果 | 两个操作互不取消 |
| 失败与重新发现 | 仅在临时 CLI 代理注入不可用，API 返回 409、旧成功清除；移除故障后页面恢复 | 未更改真实 CLI 或网关 |
| 过期、刷新、手机端选择 | 过期外显，刷新不复用旧结果；390px 控件可见且选择框位于视口内 | 桌面 Chromium 响应式验收 |
| 其他目标与无授权访问 | 外来 UUID、错误凭据、非法名称/输入被拒绝 | 未创建任何 Grant |

最终独立候选 `var/flagship/ux-e136/siq-agent-security-v2`：OpenShell 浏览器 **15 项通过**；双平台接入/权限/记录浏览器 **49 项通过**；前端 **38 文件、251 项通过**，本地与企业构建通过。Go 全量测试、vet、产品 Go 源码格式检查通过，最终嵌入 UI 的四目标交叉编译通过。Python 合同测试同时检查两类 Go 响应样例与请求正反例。交叉编译不计作 macOS/Windows 原生验收。

脱敏结果、源码/合同/候选摘要、截图与早期失败索引见 [E136 证据](../evidence/flagship-optimization-20260921/ux-openshell-discovery-e136.json)。测试使用隔离 SIQ 守护进程与 HOME，复用真实网关进行只读操作；结束后网关资源清单和公开 metadata 摘要一致。没有启动/重启原业务服务、升级已安装发行版或调用业务模型。
