## 本次功能与安全边界

列表每页最多扫描 20 条，按保存时间和稳定 ID 倒序。只接受固定格式分页位置，每个 SQL 都限制业务 tenant/user/profile；位置标识不是授权。逐条校验来源、完整性和当前数据权限，响应前用新会话再次复核，不返回正文或权限快照。撤权条目不显示，损坏/数据库异常/总时限超出返回明确失败。空可见页仍有后续位置时提示“可继续下一页”。

列表→详情准确携带会话/运行编号，返回保留分页。关闭/切换身份/隐藏页面取消请求并清空目录，重新显示时重验。正文仍要明确点击，按 E159 核对快照和摘要，以纯文本显示。保存时间不冒充执行时间，旧记录显示未知；不会把生成回复称为正式报告。

迁移仅追加 023，历史 001–022 和 checksum 原条目不变。新增可空保存时间及归属索引，原记录不改写；新内部信封 v2 绑定时间，v1 兼容仅接受空时间。同运行重复保存保留原时间和审计，内容或来源冲突拒绝覆盖。持久信封的 SHA-256 不抵御数据库管理员同时重写内容和摘要。

部署时先执行原迁移命令，再协调更新全部业务 API worker 与 Web。旧 v1 reader 不认识 v2 新记录，不能把新旧 reader 混合部署当作已支持的滚动发布。回退页面/列表路由可保留兼容 reader 与新增列；不要删除结果表、回写旧 payload 或直接回退为不识别 v2 的 reader。本批未执行用户数据库迁移。
