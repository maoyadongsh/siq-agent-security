# E147 逐单部署结果与审计

状态：本批实现与隔离验收通过；完整 ENT-UX-04 继续。承接 E146 / ENT-UX-04，优先原体验任务，SEC-F 后续清单不变。

## 行为与合同

新增只读 `GET /api/v1/change-requests/{id}/execution`，`change-execution/v1`。按已验证租户定位变更，之后检查 policy:read。仅查询该变更的部署，不使用全局第一页推断有无记录；按 created_at 降序、id 升序稳定排序。默认返回最近 20 次部署 / 50 条审计，expanded=true 返回最多 100 / 200；明确各自截断状态，超过上限不宣称全量。

响应包含本次变更状态、查询时间、部署 ID、环境 ID、当前有 env:read 时的环境名称、绑定 ID、登记目标、创建时间、部署状态、有限枚举的验证等级/独立读回结果、是否已有后端修改证据及错误摘要哈希。不给原始 receipt、错误文本或任意 verification JSON。审计另需 audit:read，未授权返回 access=denied 和空列表，不查询/泄露记录数量；授权时只返回精确关联本变更或其部署 ID 的记录标识、动作、账号、时间及合法摘要哈希。历史未绑定对象的审计不能反向猜测关联。

补齐 dev/fake deployment.create 审计 resource_id，保持状态与审计同事务；不补写或篡改历史审计。失败或回滚不能沿用旧的成功验证文案；独立读回 mismatch/unreachable/no_receipt/stale 明确展示，不能隐藏在旧 readback_verified 后面。配置读回不等于行为阻断验证，历史记录不代表当前实时检查。

## 界面与失败恢复

变更列表提供“部署与审计”入口；URL 保留所选变更，移动端同样可用。独立结果窗口支持刷新、读取失败后重试、查看更多与覆盖说明；内容区独立滚动，关闭和刷新按钮保持在窗口内；列出可操作下一步，不自动调用执行端。缺少审计权限明确说明。移除列表全局部署摘要与请求，避免错误关联。

原部署操作成功后打开同变更结果窗口并独立读回，不能仅凭 POST 200 显示生效。POST 网络/5xx 等未知结果时保留“结果待核对”，同页不提供直接重复提交；可用只读结果窗口核对。尚无部署记录不证明未执行，明确要求核对执行端。确定的前置拒绝允许修正目标后重新操作。此 UI 保护不等于持久幂等部署意图/跨页面重试或并发执行保证；完整部署预览及持久重试协议仍是后续任务。

## 验证

浏览器发现 Layout 入场动画以 pathname+search 为 key，打开/关闭 URL 弹窗会卸载整页并丢失待核对标记。改为仅 pathname 驱动整页重挂载；同页参数变化由页面及具体对象组件处理。同步给部署环境/绑定下拉框提供稳定明确的可访问名称。此修正纳入原审批、资产候选、环境接入和角色工作台回归，确认查询参数仍可恢复所选对象。

真实 API 覆盖租户/权限负向、无审计权限不泄露、旧于全局首屏的精确部署可查、foreign/orphan 审计不误关联、截断/扩大范围、无 GET 写入、错误内容不出界、时间格式与响应合同。浏览器覆盖实际 dev/fake 部署任务的创建、独立读回、关联审计、响应丢失且无同页重发、失败重试、身份缺权、刷新与移动端；fake 下发不能标记 OpenShell 实际生效。验证展示覆盖成功后漂移、失败后残留成功证据等反例。回归原审批及企业/个人主流程。
