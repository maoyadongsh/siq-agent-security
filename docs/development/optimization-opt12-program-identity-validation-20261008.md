# OPT-12：安装程序身份与升级恢复核验

日期：2026-10-08。开发基线`d962be8d`，公开证据见[程序身份与制品核验记录](evidence/optimization-20261007/install-program-identity.json)。本批改进安装诊断与升级后的身份读回；OPT-12保持implementing，总体验收10/16（62.5%）。

## 修复内容

此前密封安装记录可以通过认证，但诊断没有重新核对它所绑定的程序。程序被改写、删除，或者使用相同内容的另一路径进行诊断，OpenClaw仍可显示ready；Hermes／WorkBuddy则可能仍只显示常规待验证提示。五个实际文件反例在旧实现失败：三个平台的程序内容变化、一个缺失程序、一个同内容异路径。

现在复用密封计划中的BinaryDigest及准确程序路径，新增installation_program检查。匹配显示pass；缺失／变化／不可读取或路径不一致显示fail，配置状态incomplete。历史计划没有摘要只显示unknown／needs_verification。没有新增状态字段、迁移历史计划或信任程序自报的版本。

新程序需要明确预览和安装，应用前原有摘要复验仍生效。安装成功后新程序成为当前身份；升级中断则显示不完整，显式恢复后核对原安装程序，新程序路径不会因曾经成功应用而继续被旧记录认可。诊断不会自己批准升级或执行被检查程序。
