## 交互与安全边界

- 四个主入口：我的智能体、权限管理、安全中心、运行审计；技术视图与设置放在次级入口，旧 URL 和完整操作保留。
- 首页按框架、角色、Skill 浏览，关联仅来自 discovery relationship；未关联对象单列，不把目录关联解释为已验证调用。共享 Skill 明示来源数量。
- 权限按授权对象展示工具、期限与状态，批准、部署、后端验证生效不可混同。编辑和扩大权限复用原有资源编辑、审批挑战、运行身份与部署读回流程。
- 批量先提供撤销授权：勾选最多 50 项，后端生成 5 分钟签名预览，显示完整授权主体与影响提示，再明确确认。不是原子批次，也不是系统级进程终止；已执行副作用不能撤回。
- 批量接口 `POST /v1/grant-batches/preview` 与 `/apply` 仅管理会话可用；新合同 `grant-batch-revoke/v1`。预览无授权写入，签名绑定操作、操作者、随机批次 ID、期限、逐项 ID/版本/主体/平台/状态。客户端不得增删或替换目标。
- 执行复验签名、期限、数量、唯一目标和每项当前签名及版本，以既有 `CommitGrant` CAS 和事务审计提交。每项审计 `grant_revoke`，Note 记录批次 ID；审计失败不发布状态。单项冲突不阻止其他明确目标，逐项返回 `revoked/already_revoked/conflict/unavailable`。
- 重放只允许同版本未完成项撤权；已撤权只读返回 `already_revoked`（不声称由此批撤销），无新版本、无重复审计。其他版本变化须重新预览；不把未知提交结果当成功，不自动重批。网络失败保留预览供显式核查/重试。预览不持久化、不成为业务执行凭据；已成功变更与批次引用随现有不可变授权及审计保留。

## 不退化门禁

变更前后记录安全核心源码/测试/规则及适配器哈希，完整 Go 测试通过且原测试集合不减少；核心、规则及适配器本批不修改。覆盖已有注入/外传/污点、SEC、Authority/provenance、审批后复验、撤权、签名、回执、fail-closed。新增批量接口负向包含决策凭据拒绝、篡改/过期/重复目标拒绝、版本冲突、部分失败、重放与审计故障。Web 单测、类型检查、双构建、四平台 Go 编译、合同验证及隔离浏览器验证。

批量扩大权限、OS 沙箱支持扩展、自动强制安装适配器不在本批；不得以界面简化放宽规则。

## 已实施

1. `/agents` 为个人首页，旧 `/overview` 自动转入；原技术总览保留在 `/diagnostics`。四个主入口外的全部旧功能仍可访问。
2. 从框架查看角色，从明确的角色/配置关系查看 Skill；同名、同路径或框架标签不会被用于推断归属。共享/未关联 Skill 有独立提示和筛选。
3. `/permission-center` 提供对象/框架筛选、多选、隐藏选择计数、最多 50 项签名撤权预览、确认及逐项结果。资源调整、审批与部署仍进入既有工作台，未新增自动授权。
4. 运行审计直接连接绑定、回执与权限变更；批次结果可进入按批次过滤的操作审计。审计视图明确仅最近 200 条，失败不可伪装为空历史。
5. 使用 UI/UX 技能的批量选择、操作前确认、加载防重提交、键盘标签和窄屏检查建议；保留项目原有视觉样式。React 增量采用惰性工作台、加载代次保护与事件内提交，不将写操作放进 Effect。
