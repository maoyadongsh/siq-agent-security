## 4. 合并验证发现的问题及修复

1. 公开测评计划含一个仅本机存在的修订备份链接。将其明确标注为本机未发布档案，并提供公开报告与 Git 历史复查入口，未放宽链接检查器。
2. Dependabot 只更新 `uv.lock`，导致研究源码包的依赖清单摘要不一致。按锁文件与安装元数据同步 PyJWT 2.15.0、sdist 摘要及锁文件摘要。
3. npm 全依赖审计发现开发依赖 `source-map-js` 1.2.1 告警；只升级至 1.2.2，保持其他依赖与 peer 元数据不变，重新构建与测试后审计为 0。
4. 凭据扫描的 4,374 次新命中，去重为 1,458 个文件／行记录，均为源文件或日志的 64 位十六进制 SHA-256。例外绑定 62 个具体文件、具体字段和精确摘要值；不放行整目录、任意新摘要或认证字段。新增实际扫描器校准证明改值、改字段、同文件新凭据和复制路径仍被检出。原历史扫描覆盖保持不变。
5. 历史测评单测依赖本机封存夹具及私有隔离 SDK；公开仓库只发布了选定证据。README 明确完整测试的档案前置条件，保留首次缺失档案失败记录，不把它计作产品失败或通过，不将私有状态补交仓库。
