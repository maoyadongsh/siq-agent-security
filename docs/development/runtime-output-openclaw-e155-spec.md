# E155 OpenClaw 原生输出到运行详情

承接 E154/UX-11，使用当前安装的 OpenClaw 原生插件加载器、before-tool 包装器、实际文件工具与 after-tool relay，验证受管理安装 → 会话授权 → 真实读文件 → 加密输出 → 重启后页面显式查看。复用两框架相同的输出页验收，不直接 POST 采集接口，不替换插件成功响应。请求与文件仅为自有临时合成数据；after relay 由夹具调用，不能冒充完整模型会话。

验证默认关闭/授权不补录、原生采集、独立会话不共享输出与采集授权、越权写实际未执行、服务重启、列表不读正文、显式确认/关闭清除/刷新不重读及移动端。特别覆盖同一 sessionKey 不同宿主 sessionId 的新会话隔离。保留真实用户配置/模型/网关与已安装程序，结束清理自有临时进程。

如原生输出字段不便阅读，只对已知文本格式增加显示投影，未知类型和额外字段保留完整原字段；所有内容保持纯文本，原始采集可核对，不改变权限、合同、摘要或业务状态。原生 OpenClaw 版本及实际加载模块摘要需落证据，最终候选重跑 Hermes 回归。

现场 OpenClaw 2026.9.5 read 工具返回 content[0] 的 text/type 与 details 的 content/kind，两份正文相同。仅对唯一且完整的这 5 个采集字段、read 工具、两处类型均为 text、两份正文完全一致的结果合并显示一份正文。逐字段最多 64 Ki 字符、只解码一层字符串；重复路径、额外截断/错误字段、内容不一致或非文本都退回原字段，不推断成功/完整性。原字段可展开核对，不增加正文请求。
