## 2. 发现与修复

### 非有限模型参数

原 Nemotron 路由以两个独立比较判断 temperature 下限／上限，NaN 在两个比较中均返回 false，导致非法参数获准。已对原文件复现；改为闭区间检查，并验证两个模型路由均拒绝 NaN、正负无穷、范围外数值和布尔值。合法路由的摘要与行为不变。

### namespace 中的 Docker 所有者歧义

原未提交兼容逻辑把严格单 UID namespace 内的 overflow UID 65534 当作宿主 root。复现确认该判断为真，但其他未映射所有者也会显示为 65534，因此不能作为 root 证明。

修复后，默认只接受能够确认的 root 映射；受限 namespace 需显式配置部署者批准的 Docker SHA-256。固定 `/usr/bin/docker` 通过文件类型／权限／大小／摘要检查后，复制到当前用户的匿名 O_TMPFILE，mode 0500、没有目录项、执行前关闭写描述符，只通过只读描述符执行已批准字节。源文件随后改写不能改变执行副本；错误摘要在可见 root 场景中也拒绝。

该机制不声称隔离同 UID 恶意进程、宿主 root 或动态链接器。没有未经验证的路径回退；无法创建或执行快照时失败。客户端／上游凭据仍分离，网络与模型身份检查、撤权锁、SSE 截断后拒绝成功终态保持。
