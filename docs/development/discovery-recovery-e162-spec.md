# E162 既有环境发现的故障与恢复验收

来源为 UX-02/03/06 既定验收缺口，不增加新功能。使用 E161 固定客户端、临时 HOME 和真实 systemd 用户服务，在浏览器验证部分目录不可读时仍列出可读取结果、显示部分成功与具体扫描问题；修复权限后可重新扫描恢复。错误/不存在/符号链接目录预览应明确拒绝，不注册目录、不触发扫描，保留输入供修正。刷新读取同一结果，不自动重复扫描。

预览“可扫描”应以当前进程能够读取文件/枚举目录为依据，不能仅依据 stat 成功。明确手动输入的目录不可读取时，预览和扫描提交都应拒绝。读取必须沿用不跟随符号链接的文件入口，不读取配置正文来检查权限，不遍历目录内容，不保存凭据；预览不产生业务权限。不存在的可选平台仍为正常 missing。

最终以实际浏览器、独立后端读回、文件权限故障与恢复、负向单测和既定构建校验为证据。所有目录和单位仅属于本轮，先复原目录权限、核对服务注销，再删除夹具。正式发行签发、完整模型会话、全部发现错误类型与其他 OS 原生验收不由本项替代。
