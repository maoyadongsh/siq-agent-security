# E160 已保存运行记录目录

业务用户从固定的“分析运行记录”导航进入持久历史列表，刷新后仍可发现已提交的生成回复。目录不是全部执行历史或正式报告目录；未完成保存的运行不在本批范围。

## 合同与权限

- 新增 `siq.business-run-list/v1`，GET `/api/analysis/chat/result/list`，只接受无参数或一个 `cursor`（64 位小写十六进制记录标识）。每次最多扫描 20 条，加一条轻量定位记录判断下一页；不返回正文、公司范围、权限快照或全局数量。
- 身份由现有业务鉴权派生。数据库查询始终限制 tenant/user/profile；cursor 只定位该身份下的分页位置，不提供读取权限。不属于当前身份或已删除的 cursor 返回 400，用户可回到第一页。
- 保存时间倒序、记录 ID 倒序作为稳定次序；新插入记录通过刷新首页查看。旧记录无保存时间，排在最后，显示“保存时间未知”，不捏造执行时间。
- 逐条校验持久记录、来源和当前业务权限；返回前再逐条使用新会话复核。明确撤权/账号禁用的记录不返回；损坏、数据库故障或超时返回固定 503，不伪装成空列表。两次校验间内容变化拒绝整页。单页总时限 10 秒，正文对象逐条释放。
- 本页无可见项但仍有后续扫描位置时，明确提示继续下一页。可见项为零不推断不存在历史或用户没有权限。
- 响应及错误 no-store。列表内容不写浏览器持久缓存；身份/分页改变、页面隐藏或离开时取消请求并清空显示。回到页面重新查询当前权限。

## 数据与交互

- 仅追加迁移 023：nullable `saved_at` 和 owner/profile/时间/ID 索引。旧迁移与旧 payload 不改写。
- 新持久信封 v2 将保存时间纳入已有 SHA-256 完整性检查；v1 兼容必须对应 NULL 时间。重复保存相同运行保留第一次保存时间和原审计，内容或来源冲突仍拒绝。
- 列表展示中文运行状态、生成回复可用性、保存时间和可区分的运行标识；“查看结果”使用准确会话/运行定位。返回列表保留页位置，再次实时授权。
- 读取正文仍遵循 E159：明确点击、快照/哈希核对、纯文本显示。链接不能启动、重试、授权或发布任务。

## 验收

合同样例/负向字段校验；实际 SQLite 和隔离 PostgreSQL 持久列表、跨身份/租户/权限、损坏/故障/分页/兼容/并发幂等；迁移全链回放；组件行为、构建、实际浏览器列表→详情→返回→刷新及撤权。仅合成业务身份和数据，不替换用户在线服务。

后续仍有终态提交前恢复、安全控制台业务身份连接和正式产物归属。本批不以业务历史目录代替这些工作。
