# 业务运行时剩余验收对照

日期：2026-09-24。依据研究仓 `docs/architecture/qwen38-request-runtime-v1.md` 的“完成证据”及“创建阶段的所有权保护”，对照已保存实际证明，不新增故障场景。此核对不是重新运行模型，也不将历史源码验证自动外推为当前生产完成。

| 原要求或具体故障点 | 已有实际证据 | 结论及边界 |
| --- | --- | --- |
| 实际 HTTP 登录、新请求、模型、终态和清理 | E126；E127 及 E166 正常 SSE | 指定合成授权案例通过；不含完整数据工具→正式报告发布业务链 |
| 运行中撤权 | E166 模型输出后撤销业务 grant | 原流拒绝、独立读取 403、无成功 done、身份撤销和执行域清理通过 |
| 用户取消 | E128 v4 | 输出后取消、原 run、无成功 done及清理通过；先前失败保留 |
| 模型输出后 API 退出 | E165 v1 | 同库重启、自然租约到期、原执行失权及清理通过 |
| ExecStopPost 失败后的重试 | E169 | 身份服务中断确实造成清理失败，恢复依赖后自动重试通过 |
| 已记录沙箱、监督尚未启动时退出 | E170 | 自动清理通过，无业务重放 |
| 沙箱创建结果/监督 invocation 未保存 | E171 两轮 | 保留占位并拒绝猜测；诊断核对原始观察后清理。不能写成未知状态自动恢复 |
| Hermes 创建确认后 run ID 未入库 | E165 v2 | 独立确认真实 run 后崩溃，同库重启清理，无换绑/重放 |
| 结果与审计提交前/后退出 | E165 v3/v4 | 提交前回滚，不补造结果；提交后当前授权下读回、撤权拒绝。内存中尚未提交的正文不保证恢复 |
| 恢复时未知 child | E165 v5 | 已结束父任务、真实运行子任务、数据库只留父任务时，整个执行域回收通过。诊断显式调用既有修复函数，不等于自然业务多层委派 |
| 队列中授权过期 | 本轮审阅的实际业务证明未包含相应独立检查 | 尚未核实；不能用运行中撤权或隔离队列单测代替 |
| 第二租户请求 | 本轮审阅的实际业务证明未包含第二租户并发场景 | 尚未核实；管理员/分析员两个角色不等于两个租户 |
| 监督进程 SIGKILL | 早期 E105/E106 等组件证明已存在 | 必须核对是否绑定正式 API owner 与原合同的业务请求；组件通过不直接关闭此项 |
| 数据工具、报告工具、发布读回 | FX-01、BU-01、E84 有独立非生产发布证明 | 尚未与当前业务 HTTP、持久运行归属及用户查看链路完整连接；仍为工程未完成项 |

下一步首先核对最后四行的实现、原始证明及所需入口，再只补缺失项。前十行没有代码变化或失败依据时不重复演练。生产 IAM、正式审批、原生 CI、固定模型质量/性能与正式发行另按原任务验收，不在本矩阵中偷换完成范围。
