SIQ Agent Security · Architecture Panorama

系统架构全景 —— 本机门禁 × 企业控制面

发现 → 审查 → 人授权 → 调用时拦截 → 出事能核对。安全裁决落在本机程序而非模型：装前审查、人类批准最小权限、运行时按真实钩子拦截、每次决策留 Ed25519 签名回执；企业侧经 Edge 代理把多台机器收成同一套语义的台账。

编号流程NUMBERED FLOWS

1
装前审查 admit

候选 Skill 先审查再拷贝：恶意 → 隔离（exit 3）；声明上网/写文件等能力 → 附条件准入；干净 → 通过。

2
人批准 grant

按审查结果起草最小权限；approve 必须 --approve-as 人类，模型输出不能创建 effective 权限。

3
下发读回 effective

deploy 后由平台读回证据才标 effective；无读回显示「已部署 · 未读回」。

4
运行时拦截 decide

工具钩子问门禁：未授权能力默认拒绝；block 模式下服务不可达即拒绝（fail-closed）。

5
可核验 verify

每次放行/拒绝留 Ed25519 签名回执并入哈希链；verify 重算全链，断链 exit 4。

6
签名上报 batches

connectors 只读采集 → Edge 签名批次 → /edge/v1/batches；本机可选 sync 汇入同一台账。

7
策略闭环 OpenShell

change-request → 人审批 → deployment → OpenShell 下发（block 档热下发）→ 回执核验。

安全不变量SECURITY INVARIANTS · 任何改动不得破坏

  • tenant_id 只从验证身份派生；对象级端点先 404 后 403
  • Secret 明文不落库、不进日志 / 审计 / outbox，只存哈希或引用
  • 审计与状态变化同事务；高风险写缺审计即失败关闭
  • Edge 凭据只存哈希，每次请求在线校验，吊销即时生效
  • 模型输出不能创建 effective 权限或通过审批 —— 机器拒绝，非说明书约定
  • 生产模式禁止 SQLite、自动建表、X-Dev-* 身份头
  • 被扫描的 Skill 内容永不执行 / 导入 / eval，只存 sha256 与脱敏摘录
  • 「有威胁模式」≠「隔离」：只有欺骗、隐藏指令、提示注入、凭据外传、完整性失败才 quarantine
