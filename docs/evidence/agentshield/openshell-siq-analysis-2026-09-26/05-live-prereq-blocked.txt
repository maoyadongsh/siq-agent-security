=== 四、结论 ===
1) 若执行 --live：policy set 会真实发生（替换整段 network_policies），
   随后 rollback 必然抛 openshell_rollback_authorizer_required，
   被 _live_check 的 except Exception 捕获、打印『FAIL: 回滚失败』、ok=False、退出码 1。
2) 即：**『同一 run 内回滚作为恢复手段』在当前候选上不成立**——脚本自己没有回滚能力。
   沙箱会被留在『网络策略只剩 example.com:443』的状态，直到有人手工 policy set 恢复。
3) 因此本轮**未执行** --live；这是拒绝执行，不是失败留痕。

"""A7 前置核查（只读）：证明 --live 在当前候选上无法完成回滚。

只做一次 `policy get --full`（只读），其余全是进程内对象；不写任何策略。
"""
from __future__ import annotations

import os
import sys

sys.path.insert(0, "/home/maoyd/siq/siq-agent-security/apps/control-api")

from app.adapters.openshell.cli_backend import OpenShellCliBackend
from app.adapters.openshell.contracts import VerificationFailed
from app.adapters.openshell.operation_registry import PolicyOperation, PolicyOperationRegistry

TARGET = "siq-analysis-canary-27d1289f98fa"
backend = OpenShellCliBackend(operation_registry=PolicyOperationRegistry())

base = backend.read_effective_policy(TARGET)          # 只读：policy get --full
print(f"[read-only] target={TARGET} revision={base.revision} digest={base.policy_digest[:16]}…")
print(f"[read-only] 现存 network_policies 条数 = {len(base.network)}")

record = PolicyOperation(
    operation_id="opo-a7-precheck-readonly",
    target=TARGET,
    base=base,
    applied_revision=base.revision,
    applied_digest=base.policy_digest,
    no_op=False,
)
backend._operations.remember(record)  # noqa: SLF001
receipt = backend._deployment_receipt(  # noqa: SLF001
    operation_id=record.operation_id,
    target=TARGET,
    base=base,
    applied_revision=base.revision,
    applied_digest=base.policy_digest,
    result="applied",
)

print("\n[call] backend.rollback(target, receipt)  # 与脚本 _live_check:139 完全同形：不传 authorizer")
try:
    backend.rollback(TARGET, receipt)
    print("[result] 未抛异常 —— 与本核查预期不符，需重新判定（未写入任何策略）")
    sys.exit(3)
except VerificationFailed as exc:
    print(f"[result] VerificationFailed: {exc}")
    print("[meaning] 回滚在**写之前**就失败：脚本 _live_check 的 except Exception 会打印"
          "『FAIL: 回滚失败』并把 ok 置 False，退出码 1 —— 而 policy set **已经发生**。")
    sys.exit(0)
except Exception as exc:  # noqa: BLE001
    print(f"[result] 其它异常 {type(exc).__name__}: {exc}")
    sys.exit(4)
