## 1. 完成的修复

- **身份丢失保护**：磁盘 seed 缺失仅在首次引导状态允许生成（配置/实例/格式元数据、当前写锁和空目录）。已有历史、未知文件、符号链接或读取失败均拒绝补建，提示恢复原密钥；已有有效密钥仍可使用。serve 在恢复 Grant 事务前加载身份，不先用丢失身份的状态恢复事务。显式 SeedEnv 既有合同不变。
- **真实身份验证**：通过 rc.5 的 init/serve/inventory 入口产出历史；删除密钥后 serve 退出 1，全部剩余文件摘要不变、没有新密钥；恢复原密钥后 inventory 再次成功。无全新身份替换旧实例。
- **旅程误报修复**：旧响应缺 scope/task_executed 必须失败；必须传入预期候选 SHA；副作用断言比较操作前修订与操作后修订，不能与刚更新的自身字段比较；非 hold 必须明确为 deny；取消必须返回 denied；最终策略摘要必须等于起始值。回滚放在撤权之前，不允许依靠已撤销的 Grant 恢复权限。
- **工具真实性**：旧 `--version` 不是本产品命令，原脚本忽略其失败；现改为 `version` 并验证退出码及输出。env-script 通过 shell 位置参数传入，避免路径被解释成命令。异常路径清理本脚本持有的子进程。
- **L01 测试通道修复**：通用 CLI 助手将 stdout/stderr 合并，破坏 JSON 协议；行为探测改为直接使用既有有界 Runner，独立解析 stdout，非零退出、超限、未知错误仍不算阻断。错误诊断输出明确区分结果与独立接收计数。
- **证据保护**：新公开旅程报告脱敏绝对工作区路径；私有目录设置 0700/0600，并加入 Git 忽略规则。历史批次补公开文件 SHA256SUMS 和 REVIEW-NOTICE，仅证明当前完整性，不补造历史验收。
