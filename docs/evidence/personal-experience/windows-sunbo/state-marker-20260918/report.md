# Windows 非法状态标记拒绝

同一干净源码 185a0d6 和原生二进制（摘要见 summary.json），在专用私有根新建状态并执行 init。分别修改本批 state-format.json 为：非法 JSON、尾随 JSON、重复 format_version、未知字段、null 版本、字符串版本、非法时间戳、非法目录身份、缺失 schema。

每次修改后记录全部目录名称及文件 SHA256，再执行真实 init。9 项均非零退出且树与文件内容完全不变。最后恢复精确原始标记，完整快照相符，state-status 退出 0。仅修改自有测试标记，未启动服务、注册任务或使用模型。

覆盖 P03-STATE-01。不能据此声称含既有 Grant revision、可验证授权与撤销状态的迁移快照要求 P03-STATE-07/12 已通过。该批使用已初始化状态的非法标记夹具，不伪造历史版本。
