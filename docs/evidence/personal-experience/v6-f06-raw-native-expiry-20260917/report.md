# F06 Linux/OpenClaw 原文 Grant 自然到期后的原生调用

日期：2026-09-17。固定 SIQ 候选 Linux/arm64 SHA256 `ac447ac92e65997952dc5a19ead7a83a8512924948a43f986d7f0d66aa0366ff`；真实 OpenClaw CLI/插件根为 2026.5.12、Node 22.22.1。两腿均用隔离 HOME 与状态目录、真实 `openclaw agent --local`、真实托管插件钩子和 SIQ daemon；模型及操作者是确定性夹具，未调用付费模型。每腿独立启动和清理，不接触用户日常配置。

三腿的 SIQ 二进制摘要相同。脚本摘要不同：到期腿开始前修正了脚本读取运行时凭据的字段错误；在完成到期腿后，又加了宿主 SDK 入口预检并跑兼容预检回归。默认撤销路径未改，不把三腿称为逐字节相同的脚本。到期模式由 `--raw-expiry-seconds 90` 明确启用，默认仍按历史撤销流程执行。公开 JSON 未包含本机完整路径、运行时令牌或原文；私有过程日志放在忽略的 `native-expiry-private/`，目录 0700、文件 0600。

失败样本保留：初次定位误用了本机另一份 OpenClaw 2026.3.11，插件所需 SDK 模块不存在，原生钩子未加载，禁止写入却实际执行；撤销对照在同一错误宿主也失败。这两次不能计入 2026.5.12 的产品验收。切换到日常 CLI 对应的 2026.5.12 后，撤销对照通过；到期首轮在期限后因测试脚本误读 `credential` 字段而停止，尚未发起到期后原生调用。修正为读取本批创建的 `credential_path` 后，完整到期腿通过。随后预检负例在错误宿主上退出 1 且未创建原生写入夹具；正确宿主的回归通过。没有删除或伪装失败记录。

SDK 入口预检只能排除这次已观察到的错误宿主版本，不单独证明插件已加载或全部工具路径受管；真实负向调用与回执才是本批运行证据。本证据仅关闭本机 Linux/OpenClaw 的原生**到期后新调用不再产生原文**这一腿。它不证明真实用户批准、Skill 来源归属、GUI 通知点击、Hermes 的同类自然到期、Windows/macOS 结果或完整 F06/N09 发布验收。授权到期与原文保留期限是不同边界：本腿检验停止新增采集，未等待一小时保留期限清除旧密文；历史双任务到期清理另有独立证据。
