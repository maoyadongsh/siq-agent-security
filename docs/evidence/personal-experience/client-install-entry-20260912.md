# M58：已签名客户端的稳定路径安装入口

日期：2026-09-12。codex/personal-client-upgrade-recovery 的本地开发增量。

## 实现

Linux client-install --manifest FILE --binary FILE --confirm-install，支持 --port、--runtime、--open-ui。先检查发行签名/v2 兼容声明，Stage 保存程序与清单，再检查暂存版本和摘要路径。只执行稳定路径的 setup，通过明确环境变量选择同一状态目录，不使用 shell。子进程最长 120 秒，输出丢弃；失败保留暂存材料并要求检查服务状态，不推断超时已撤销后台影响。

启动后检查签名 unit、manager 活跃进程、目录健康和运行版本，全部符合才报告成功。程序不再依赖原下载路径；已有不同 unit 保持既有拒绝行为，升级使用独立事务入口。没有修改 PATH、登录自启或智能体权限。

## 验证

- Go 全量、vet、CLI race、四目标交叉构建、diff 检查通过。
- 产品入口测试拒绝无确认、非法端口和非发行根签名的现有 v2 固定样例；验证样例确实存在，拒绝后无状态目录。
- 准备流程采用包内测试回调，覆盖初次校验失败不暂存、暂存失败、二次验证失败、声明版本漂移、错误暂存位置和摘要目录不符拒绝；成功固定稳定路径和版本。
- 子进程环境测试证明新旧状态变量去重且只使用选定状态目录。
