## Ownership and attribution

Copyright 2026 maoyadongsh and contributors. The repository owner confirmed ownership of project-created code and original research material on 2026-09-08. The public account name is used for attribution; no legal name, institutional affiliation or paper authorship is inferred.

## Project-owned material

The root [Apache-2.0 license](../LICENSE) covers project-owned software, schemas, scripts, synthetic executable fixtures and ordinary documentation. The exact original research document paths in [scope.json](scope.json) use [CC BY 4.0](CC-BY-4.0.txt). Embedded code examples remain Apache-2.0. A future document is not automatically added to the CC list.

## Third-party material

Third-party patches, vendored assets, fonts and dependencies retain their own licenses and attribution. Their terms take precedence over the root default for those works. Consult [third-party notices](../THIRD_PARTY_NOTICES.md) before distributing binaries or bundles. Test fixtures may contain fictional license declarations: those declarations describe test inputs, not additional real contributors.

## Exclusions and citation

Model weights, external APIs, upstream software installed separately, private state, unpublished video assets, user data, trademarks and third-party quotations are outside this grant. Historical release archives are unchanged; do not claim that their packaging already contains these new notices. Research citation is encouraged, not an extra condition on Apache-licensed software. CC material attribution can use `maoyadongsh, SIQ Agent Security`, the repository URL, the CC license link, and a description of changes.
