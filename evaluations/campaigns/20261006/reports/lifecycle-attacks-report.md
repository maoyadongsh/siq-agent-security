## 步骤、结果与产品意义

| 行为 | 观察结果 | 解释 |
| --- | --- | --- |
| 正常 V1 读取 | 工具返回本批新植入随机标记，签名 allow；标记不在用户提示中 | 防止把所有调用都拒绝误计为防护有效 |
| 候选新增 company-b 写权限 | 比较接口展示权限变化并要求确认；未批准时准备更新返回 409 | 扩权需要明确批准 |
| 批准前原实例尝试写 | 原生 write 工具收到拒绝；签名 reason 为 `grant_scope_violation`；目标文件不存在 | 未批准候选不授予原实例额外权限 |
| 显式批准候选，但不更新/激活旧实例，再尝试写 | 同样签名拒绝且无文件效果；旧 Grant 仍无写权限 | 候选批准不等于旧实例获得新权限 |
| 不确认、伪造计划签名、替换操作员 | 分别返回 400、409、409；目标和其他采集对象摘要不变 | 更新确认、计划完整性和主体绑定在本例生效 |
| 替换准备区中的 SKILL.md | 请求发生在替换和还原之间；提交 409，目标不变 | 本机准备副本内容绑定生效，不是远端仓库来源替换实验 |
| 目标出现用户未知文件 | 更新提交 409；原目标保留 | 不静默覆盖存在冲突的用户目录 |
| 冲突状态明确卸载 | 返回 `cleanup_pending`；旧 Grant revoked；SKILL.md 与未知文件均保留 | 撤权可完成，同时保留不能安全删除的文件 |
| 正常重启／SIGKILL 后原状态重启 | 新进程只读查询仍为 pending、旧授权仍撤销、文件保留 | 所测持久状态没有被重启静默恢复为授权或自动删除 |
| 操作员把未知文件移至安全位置后明确重试 | 同一卸载请求完成删除，移出的文件内容保持 | 冲突解除后可恢复完成 |
| 原路径新建用户目录后重放旧卸载请求 | 返回已移除，保留新目录及文件 | 已完成卸载不误删后来建立的用户对象 |

每次拒绝同时检查 HTTP 结果与独立文件摘要。离线验签检查完整回执链、CLI 捕获的公钥及实际工具名/参数摘要；替换注入有前后摘要和单调时钟窗口。七个阶段投影必须与真实 HTTP 读回及文件采集一致。其他 profile 与一个第三方命名目录中的独立文件保持不变。

## 003 来源完整性扩展

此批在协议中预先登记 `source_integrity=true`，添加三次真实 HTTP 操作及六项独立检查：

1. 候选已经批准后，改写最初导入的本地目录，再用完全相同 import_id/路径重放导入请求。返回 200，完整导入记录与最初 201 时相同，目标摘要不变。说明同一导入请求仍指向冻结快照，不会把路径中的新字节偷换进旧批准。它不是对新导入内容的恶意性检测。
2. 准备更新前篡改已导入 blob 的 SKILL.md，提交原候选和原批准修订号，返回 409 `skill_install_changed`，目标不变。恢复原字节后正常准备成功。
3. 准备计划后再次篡改同一导入 blob，提交原已签计划，仍返回 409 `skill_install_changed`，目标不变；最后还原测试对象。

三个注入均记录变更前后摘要、还原摘要和请求位于变更窗口内的单调时钟证据。导入副本篡改由测评器对自有目录直接实施，代表完整性故障注入，不代表低权限攻击者能访问产品状态目录。远端 Git/HTTPS 地址或发布者身份替换未在此批执行；旧批准拒绝新的导入身份、远端正常版本更新及生产抓取策略仍需单独验证。

## SIGKILL 证据与限制

002 的 [crash.json](../data/lifecycle-attacks-002/crash.json) 记录被测 daemon 的 PID、boot ID、启动时钟、杀前存活、`SIGKILL` 和退出值 -9；它必须绑定首次启动身份。第二次启动身份不同，复用同一状态目录。批次结束后两个 daemon 身份均已不存在，原生 CLI 全部退出，资源清理记录为空。

强杀发生在卸载已落入 `cleanup_pending` 且工具进程退出之后。它验证该时点的进程崩溃恢复，不是提交事务内部精确断点、工具 pending/审批中断、磁盘写失败或断电实验。002 冻结的 `legacy-report.json` 沿用了“normal process restart”旧描述；该字段不参与评分，实际重启模式以冻结协议、crash.json、启动身份及独立评分为准。后续执行入口已修正文案，历史证据不改写。

第三方对象只是未启用的插件目录独立文件，没有实际运行第三方 hook。本项不证明活动 hook 配置合并/卸载正确，不证明同 UID 对手隔离；真实来源身份替换、独立撤权派发竞态、决策服务断连、审批恢复、其余原生宿主/OS 后端矩阵仍待实施。
