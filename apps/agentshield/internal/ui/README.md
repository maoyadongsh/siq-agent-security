# siq-agent-security 本地控制台（embed）

`embedded/` 是当前受版本控制的本地 Web 构建产物，由本包通过 `go:embed` 装入 Go 二进制。源码入口是 [apps/web](../../../web/README.md)，不是在嵌入目录直接修改页面。

## 构建与服务

从仓库根执行：

```bash
make -C apps/agentshield ui
# 或进入 apps/web 后执行 npm ci 与 npm run build:local
```

随后重新构建 Go，二进制才包含新页面。Go 测试不依赖 npm，不能代替 Web 类型、单元与浏览器检查。个人服务提供 SPA 与不含 secret 的 `/ui-config.json`；管理员配对和 API 权限由 server 执行。开发服务入口、固定代理端口和 Windows 命令见 [Web README](../../../web/README.md)。

## 当前个人流程

| 入口 | 关键行为 | 结果的解释 |
| --- | --- | --- |
| 概览、资产与设置 | 盘点、确认资产、发现并接入具体宿主实例 | 文件/连接/运行验证分层，配置成功不等于工具已保护 |
| Skill 导入与安装 | 目录/ZIP/公网 HTTPS ZIP 候选，检查、权限准备、安装预览与显式确认 | 候选副本、授权、目标与摘要逐阶段复验；本地路径不放入 URL |
| 已安装 Skill 与更新 | 检查安装身份、更新预览、移除、失败恢复 | 操作绑定原事务；重试不得另建重复副作用；保留未知用户对象 |
| 确认待办 `/confirmations` | 展示平台、会话、期限、脱敏参数与仅一次操作范围 | 批准记录不等于执行；预留无结果显示 uncertain，不能盲目重试 |
| 任务活动与回执 | 来源、动作、执行观察、效果与完成核验 | 工具自报、签名记录和实际效果分别显示 |
| 隐私与通知 | 按需原文权限、导出与待办提醒 | 原文默认关闭；通知只打开详情，不批准任何请求 |

HTTPS ZIP 入口要求直接下载链接，不解析仓库首页或登录页面；预期 SHA256 与 ZIP 内目录可显式指定。检查或签发不自动完成安装，安装不自动获得 Skill 执行上下文。目标平台、Windows 路径权限和宿主识别按服务端能力与[平台范围](../../../../platforms/README.md)限定。

## 审批、断连与恢复

确认页定期刷新近期请求，断连时暂停处理；已过期、已处理或权限失效的请求不继续提供批准按钮。长期权限进入独立草稿/批准/部署流程，不由一次 hold 扩权。Hermes 初次 hold 被阻断，批准后仍需受支持的同操作重试和执行预留，不能声称自动恢复原调用。

导入、预览与安装按原 request/plan/install ID 查询恢复；响应丢失不自动创建第二次安装。失败恢复复验归属与签名，用户新增或修改内容保留并报告冲突。成功安装的卸载走正式移除流程，不能借失败恢复删除。

浏览器通知由用户主动开启，只显示待办数量、协调同源窗口去重；后台和三系统实际投递仍以专项证据为准。操作细节见[个人手册](../../../../docs/personal-client-operation-guide-20260916.md)，阶段与原生验证见[测评入口](../../../../evaluations/README.md)。早期 M18–M25 报告保留原阶段范围；当前页面不再把已经接通的后续安装能力描述为尚未开发。
