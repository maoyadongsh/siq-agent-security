# siq-agent-security 本地控制台（embed）

`embedded/` 由 `apps/web` 的本地模式构建写入，再由本包 `go:embed` 进 `siq-agent-security` 二进制。

```bash
make -C apps/agentshield ui
# 或：cd apps/web && npm ci && npm run build:local
```

未构建时保留占位 `index.html`，`siq-agent-security serve` 的 `GET /` 仍可响应，Go 测试不依赖 npm。

## 个人确认待办

启动 `siq-agent-security serve` 并完成管理配对后，在导航中打开“确认待办”（`/confirmations`）。运行操作展示所属平台、会话、截止时间和脱敏参数摘要；核对后可批准本次请求，也可直接拒绝。已处理、过期或权限失效的请求不再提供处理按钮。长期权限待办会进入指定授权的审阅页，继续单独批准、部署和接入。

页面每 5 秒刷新近期请求，断连时暂停确认；回执中的“查看确认状态”可定位相应详情。窗口外历史继续在回执中查询。批准记录不等于执行结果，也不会扩大长期权限。Hermes 目前不能在批准后自动恢复已阻止的调用；可以在“待办提醒”中主动开启浏览器通知；拒绝通知权限不影响此页面使用。通知只显示待办数量，点击只打开详情。同源多窗口协调去重，短时间内的新请求合并提示。请保持管理页面打开，后台启动器与三系统实际投递仍待独立验收。

个人 Skill 导入审阅（M18）：`/skill-imports` 提供本机目录/ZIP 路径输入、检查结果和签名导入历史；详情重新校验完整副本。请求 ID 支持断连后的查询与原请求显式重试，来源路径不进入 URL/Web Storage。M18 仅保存并检查候选，当时尚未接通浏览器文件上传、链接获取、权限批准及平台安装；不能把准入结果显示为已保护。对应规格 ADR-034，隔离 Linux Chromium 证据见 `docs/evidence/personal-experience/skill-import-review-20260911/`。


HTTPS ZIP 导入（M19）：来源选择增加公网 HTTPS ZIP 下载链接，可填写 ZIP 内的 Skill 目录和来源方提供的预期 SHA256。下载后固定副本并检查，结果显示下载时摘要与所选目录；本地和下载历史均可审阅。CLI 对应 `import-skill --url https://example.com/skill.zip --archive-path repo-main/skills/report --sha256 <64位小写摘要> --actor <操作者>`，目录和摘要参数可省略。只接受直接 ZIP 链接，不解析仓库首页或登录页面。尚未接通权限批准与平台安装，详见 ADR-035。M19 的受控 TLS 验证和浏览器夹具范围独立登记，不能用其代替真实平台验收。


导入权限准备（M20）：非隔离候选结果增加“为目标智能体准备权限”，从已发现的 Hermes 实例选择目标，准备后进入既有签发页编辑资源与期限并人工批准。签发页显示完整副本/检查摘要与候选链接；服务在签发挑战和批准时重新校验副本。网络响应丢失时可按原请求恢复，不重复创建草稿。当前尚未接通 Skill 安装事务，因此这种批准仍不能部署或获得运行身份；OpenClaw/WorkBuddy 目标选择和安装读回继续开发，不能把配置目录夹具当作宿主实测。


安装预览（M22）：在导入候选的 Hermes 授权批准后，签发详情新增“安装预览”。目录名从 Skill 名称预填，可以修改；点击“生成安装预览”后显示目标位置、文件数量、内容/权限摘要和五分钟期限。响应丢失可重试原请求，刷新按位置栏的 install_plan ID 完整复验，不自动创建新的计划。来源、批准权限或目标变化时撤下旧预览。当前完成的是私有暂存和核验，实际安装确认、平台写入、恢复与读回仍在开发，不代表 Skill 已安装或受保护。合同与范围见 ADR-037/038，隔离浏览器证据见 `docs/evidence/personal-experience/skill-install-preview-20260911/`。


安装确认与恢复（M25）：在有效预览中核对位置、内容和权限，勾选确认后点击“确认安装 Skill”。操作者须与生成预览时一致。完成后显示目标内容核验结果；尚未验证平台识别和运行保护，不自动启用运行权限。位置栏保存 install_id，刷新仅查询原操作，响应丢失不会再次安装。已失败或中断的操作可在结果卡片勾选“确认恢复此次失败安装”后恢复；撤销授权、候选无法读取时仍保留结果入口。用户新增、修改或无法确认归属的内容会保留并报告恢复冲突。成功安装不能通过失败恢复入口卸载，正式更新/卸载继续归 UX-010。源码绑定与隔离浏览器证据见 `docs/evidence/personal-experience/skill-install-management-20260911/verification.json`。
